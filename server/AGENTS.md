# server/ — 서버

## 맡은 일
Fastify 서버 전체: 접근 검문, 검토 파이프라인, 근거 수집·저장, 저장 암호화, 보호 저장소, 외부 통신 가드, AI 연결, 백업, 공개 번들 가져오기. 진입점은 `index.ts`(시작 순서), 라우트와 검문은 `app.ts`, 베타 화면 라우트는 `beta-v8.ts`, 보안 라우트는 `security-routes-v8.ts`.

## 맡지 않는 일
- 화면 코드(`src/`, `beta/`)를 가져오지 않는다. 화면과는 HTTP로만 이야기한다.
- 서버와 화면이 함께 쓰는 타입·문구·날짜 규칙은 `shared/`에 둔다. 서버 안에서만 쓰는 것만 여기에 둔다.
- 후보 계층 파일(`*-v2`~`*-v7`: 컴플라이언스, LegacyBridge, 안전관리자 의무, 교육, 첨부 그래프 등)은 기본 경로에서 가져오지 않는다. `createApp`은 시험용 가짜 사용자(`synthetic: true`)가 주어질 때만 연결한다.

## 반드시 지키는 것
- 시작 순서(`index.ts`): 실행 키 읽고 지우기 → 외부 통신 가드 설치 → 저장 암호 키 열기 → 저장소·앱 생성 → AI 전송 승인 관문 → 평문 이전 → 보존 삭제 → 번들 가져오기 → `running` 검토 실패 처리 → 수신 시작. 순서를 바꾸면 가드 우회나 평문 저장이 생긴다.
- 접근 검문 순서: 루프백 → Host → Origin → 교차 사이트 → 경로 판정 → 세션 → CSRF → 1회용 값(`bootstrap`만, `launch-token-v8.ts`: 5분·한 번만·HMAC 서명, 쓴 값은 메모리에만 기억). 판정은 `routedPath`로 한다. `req.url`의 접두어로 판단하지 않는다.
- 모든 외부 호출은 허용 목록을 지난다. 새 호스트는 목록과 시험을 함께 바꾼다. `net`/`tls` 직접 사용, 다른 HTTP 클라이언트 금지.
- 모델 출력은 `legal.ts`의 `enforceIssue`를 거친 뒤에만 `reviews.ts`에서 저장한다. 기본 경로에서 `clear_risk`를 내는 코드를 새로 만들지 않는다. `evaluateRule`은 `human_review`만 돌려준다.
- 새 표를 만들면 암호화 대상(밀봉 표) 포함 여부를 정하고, 제외하면 이유를 주석으로 남긴다.
- 오류 응답은 `safeMessage`를 거친다. 본문·키·파일 경로를 로그·감사 기록·오류에 넣지 않는다.
- 하위 프로세스는 `child-env-v8.ts`의 허용 환경변수만 넘기고 `windowsHide: true`를 준다.
- `beta-contract-v8.ts`는 화면과 같이 쓰는 타입이고 화면 잠금 대상이다. 바꾸면 잠금 시험이 실패한다.
- 설치판(`SHE_INSTALLED=1`)에서는 MCP, 공개 업데이트, 전자민원, 평문 백업이 403이다.
- 변경 요청은 한 번에 하나만 처리한다(진행 중이면 409).

## 구현 방식
- 요청 검증은 zod 스키마(`schemas.ts`, `shared/types`)로 한다. 오류는 `{error:"한국어 메시지"}`.
- 저장소는 `node:sqlite`(WAL, FTS5 trigram). 상태 변경 묶음은 SAVEPOINT 또는 `BEGIN IMMEDIATE`로 감싸고 실패하면 되돌린다.
- 날짜는 `shared/dates`의 `koreaDate()`로 계산한다.
- 파일 이름 `-v2`~`-v8`은 만든 단계를 뜻한다. 단계 접미사가 없는 파일이 기본 경로의 핵심이다.

## 시험
- 위치: `tests/`. 데이터 폴더는 임시 폴더, 시계는 고정 시계. 사용자 `.local`을 읽거나 쓰지 않는다.
- 새 검문·허용 호스트·밀봉 표·`clear_risk` 차단은 각각 거절 경로를 확인하는 시험을 둔다.
- 서버를 띄우는 E2E는 격리된 `SHE_DATA_DIR`로 돌린다.
