# src/ — 옛 화면

## 맡은 일
`/`에서 서비스되는 첫 화면(React 19 + Vite, 빌드 결과는 `dist/`). 검토 요청, 결과·근거 보기, 문서 업로드, 접수(intake), 공공 API, 검증, 승인 화면.

## 맡지 않는 일
- 서버 코드를 가져오지 않는다. 서버와는 `/api/…` HTTP로만 통신한다.
- 베타 화면(`beta/`)과 코드를 공유하지 않는다. 공용 타입은 `shared/`에서 가져온다.
- 결과 판단·분류를 화면에서 다시 계산하지 않는다. 서버가 준 분류와 문구를 보여 준다.

## 반드시 지키는 것
- **이 화면의 파일(29개)은 해시로 잠겨 있다.** 하나라도 바뀌면 화면 잠금 시험이 실패한다. 바꿔야 하면 사용자 승인을 받은 뒤 파일을 고치고 잠금 스크립트로 해시 목록을 다시 만든다. 승인 없이 잠금 스크립트를 돌리지 않는다.
- 필수 표시 "검토 후보 — 법적 판단 아님, 베타"와 `shared/result-language.ts`의 문구를 그대로 쓴다. "위험", "위반" 같은 단정 문구를 화면에서 만들지 않는다.
- 변경 요청은 세션 쿠키와 `X-CSRF-Token`을 붙여 보낸다. 409(진행 중)는 오류가 아니라 대기 상태로 보여 준다.
- 키·본문을 화면 로그나 URL에 남기지 않는다.

## 시험
- 변경 뒤에는 화면 빌드와 서버를 띄우는 E2E(`scripts/e2e*.mjs`)를 격리 데이터 폴더로 돌린다.
- 화면 변경이 필요하면 베타 화면 E2E도 함께 돌려 기능이 풀었다 묶은 뒤에도 같은지 확인한다.
