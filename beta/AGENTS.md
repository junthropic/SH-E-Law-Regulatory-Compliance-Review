# beta/ — 베타 화면

## 맡은 일
`/beta/`에서 서비스되는 Store 베타의 주 화면(React 19 + Vite, 빌드 결과는 `dist-beta/`, 설정은 `vite.beta.config.ts`·`tsconfig.beta.json`). 키 입력(`KeysPage`), 자동 수집·데이터(`DataPage`), 결과 보기·자가 검토(`ReviewPage`), 표시 문구 변환(`present.ts`), API 호출(`api.ts`).

## 맡지 않는 일
- 서버 코드를 가져오지 않는다. 서버가 내보내는 `beta-contract`(타입 파일)만 서버와 함께 쓴다.
- 판단을 다시 계산하지 않는다. 서버가 준 분류·문구를 보여 준다.
- 옛 화면(`src/`)과 코드를 공유하지 않는다.

## 반드시 지키는 것
- **`beta/`, `dist-beta/`, 베타 빌드 설정, `beta-contract`는 해시로 잠겨 있다.** 바꾸려면 사용자 승인 → 수정 → 잠금 스크립트로 재잠금. 잠금을 풀었다 묶어도 기능이 그대로여야 한다.
- 결과 화면과 내보내기에 항상 "검토 후보 — 법적 판단 아님, 베타"를 표시한다. 자가 검토는 "자가 검토 — 독립 검토 아님"으로 표시한다.
- 서버는 키가 저장되었는지(`configured`)만 돌려준다. 화면은 키 값을 다시 보여 주지 않고, 로그·주소에도 넣지 않는다.
- 앱 제거 시 자료가 지워진다는 고지문과 백업 안내를 화면에서 뺄 수 없다. 고지문 내용은 서버(`/api/beta/notice`)가 정한다.
- 외부 주소로 요청을 보내거나 외부 스크립트·글꼴을 불러오지 않는다(글꼴은 `fonts/`에 포함).

## 시험
- 베타 빌드 시험과 베타 E2E(`scripts/e2e-beta-v8.mjs`)를 통과시킨다. 문구가 바뀌면 Store 스크린샷을 다시 찍는다(`scripts/capture-ui-v8.mjs`).
