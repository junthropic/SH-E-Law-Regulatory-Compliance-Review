# SH·E Law Check

국내 환경안전보건 담당자를 위한 **근거 중심의 로컬 법규 검토 도구**입니다. 첫 범위는 위험물 저장·취급 및 인허가입니다. 사업장의 상황을 입력하고 시·도와 기준일을 선택하면, 법규 원문과 질문을 다음 세 범주로 정리합니다.

- **명확한 법률 리스크:** 검토자가 승인한 규칙, 확인한 사실, 원문 인용, 예외·적용 범위가 모두 충족될 때만 생성
- **사람의 판단 필요:** 법적 해석, 예외와 회신의 적용 가능성을 사람이 검토
- **추가 자료 필요:** 사실, 원문, 별표, 최신성 또는 검토 범위가 부족한 경우

`100% 법적 정확성`이나 `전국 검증 완료`를 표시하지 않습니다. 모델이 만든 명확한 리스크는 사람의 판단 필요로 낮추고, 원문에 없는 인용은 결론을 보류합니다. 허가증을 입력하지 않았다는 이유로 무허가로 판단하지 않습니다.

## 실행

Windows 10/11과 Node.js **24 이상**이 필요합니다. 저장소 폴더에서 IDE 통합 터미널로 실행합니다.

```powershell
npm ci
npm run build
npm start
```

브라우저에서 <http://127.0.0.1:4317>을 엽니다. 초기 설치·빌드 후 `Start.vbs`를 더블클릭하면 콘솔 창을 표시하지 않고 실행합니다. 이미 앱이 실행 중이면 기존 주소를 사용하세요. 기본 주소는 `127.0.0.1`이며 LAN 공개용 서버가 아닙니다.

숨김 실행을 종료하려면 **연결 설정 → 로컬 앱 종료**를 사용합니다. 통합 터미널에서 실행했다면 해당 실행의 `Ctrl+C`로도 종료할 수 있습니다.

1. **연결 설정 → ChatGPT 구독 연결:** 본인 계정으로 로그인하고 사용 권한을 허용합니다. 유료 API 키로 자동 전환하지 않습니다.
2. **법제처 OC 저장:** 국가법령정보 공동활용에서 발급받은 인증값을 입력합니다.
3. **법규·갱신 현황 → 지금 갱신:** 실제 원문을 수집합니다. 초기 번들은 비어 있습니다.
4. **자료함:** 보유 회신·허가증·SDS를 올리고 추출문과 표·수치를 원본과 대조합니다.
5. **새 법규 검토:** 소재지, 기준일, 상황, 첨부자료를 선택합니다. AI를 사용할 때 사용 가능한 모델을 불러와 선택합니다.
6. 추가 질문에 답하면 **새 검토**가 생성됩니다. 기존 기록과 당시 근거는 유지됩니다.

ChatGPT 연결 없이도 자료·사실 확인 목록, 수량 계산, 자료함과 기록 기능을 사용할 수 있습니다. AI 분석에는 질문과 선택 자료의 발췌가 OpenAI에 전송됩니다. 전송 전 일반 전화번호·이메일·주민번호 패턴을 가리며, 모든 영업정보의 자동 제거를 보장하지는 않습니다.

현재 수집기는 위험물 키워드에 해당하는 법제처 자료를 찾습니다. 법규명 변경·다른 이름의 위임 규정·시군구 고유 규정·폐지 후 대체 법규까지 자동으로 빠짐없이 찾는다고 간주하지 않습니다. 경기도·울산·인천의 실사례를 먼저 검증한 뒤 다른 시도로 확대할 수 있도록 [운영 검증표](docs/validation.md)를 제공합니다. 환경·산업안전·보건 전반의 승인 규칙은 아직 제공하지 않습니다.

## 데이터 보관

| 위치                                               | 내용                                          | Git 반영                    |
| -------------------------------------------------- | --------------------------------------------- | --------------------------- |
| `server/`, `src/`, `shared/`, `scripts/`, `tests/` | 소스코드·가상 시험 데이터                     | 포함                        |
| `data/public/bundle.json.gz` (초기 JSON 호환)       | 공식 법규 전문·시행일·공포일·수집시각·SHA-256 | 포함                        |
| `.local/private.sqlite`                            | 실제 질문·답변·검토·업로드 메타데이터         | 제외                        |
| `.local/originals/`                                | 업로드 원본                                   | 제외                        |
| `.local/*.dpapi`                                   | OAuth·OC·승인 후 민원 세션                    | 제외, Windows 사용자에 결속 |
| `backups/`                                         | 비공개 자료 백업                              | 제외                        |

화면의 백업에는 개인자료 원본이 포함됩니다. 인증정보는 제외됩니다. 복원한 근거·문서·규칙은 재확인 상태로 돌아갑니다. Windows 계정을 바꾸면 인증정보는 다시 연결하세요.

설정 파일을 선호하면 `.env.example`을 `.env`로 복사합니다. `npm start`와 `npm run sync`는 `.env`를 읽습니다. 기본 데이터 폴더를 변경할 때에는 `SHE_DATA_DIR`를 사용합니다.

## 공개 자료 자동 갱신

기본 브랜치의 `.github/workflows/public-law-sync.yml`은 한국시간 06:00에 실행하도록 설정되어 있습니다. GitHub 예약 작업은 지연될 수 있습니다. `LAW_OC`를 저장소의 **Settings → Secrets and variables → Actions**에 등록하세요. 인증값을 코드나 커밋에 넣지 마세요.

수집기는 **독립 임시 DB**를 사용합니다. 개인 DB를 공개 번들로 내보내는 기능은 없습니다. 출처별 실패 시 마지막 성공 전문을 보존하고 실패 상태를 기록합니다. 일부 실패도 Actions에 실패로 표시합니다. 로컬 앱에서는 연결 설정의 **Git 공개 법규 가져오기**를 눌러 기본 브랜치의 공개 번들을 반영할 수 있습니다.

```powershell
npm run sync
npm run publish:check
```

## 시험

```powershell
npm run check
npm run publish:check
```

앱을 실행한 상태에서 Chrome 또는 Edge가 설치된 PC에서:

```powershell
npm run test:e2e
```

E2E는 독립 헤드리스 브라우저를 사용합니다. 시험용 기록을 생성하므로 실제 업무 DB와 분리한 `SHE_DATA_DIR`로 서버를 실행하세요. Edge 사용 시 `SHE_TEST_BROWSER=msedge`를 지정합니다. 인증·법규 응답의 자동시험은 가상 데이터를 사용하며, 실사이트 인증·전국 법률 검증의 대체가 아닙니다.
