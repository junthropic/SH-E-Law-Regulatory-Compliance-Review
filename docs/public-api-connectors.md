# 공공자료 API 연결 및 검증

화면 분류는 업무 분야 7개(법령·해석·기술지침, 화학물질·위험물, 재해·사고사례, 환경·폐기물, 기계·보호구·방호장치, 소방용품·고압가스, 주소·입지)를 사용한다. 아래의 기존/추가 구분과 A/B 번호는 도입 이력 및 신청 목록 참조용이며, 키 등록·조회 연결 상태는 분야와 독립적으로 표시한다.

2026-10-08: 공공자료 조회에서 32개 서비스의 실제 검색·결과 확인·자료함 저장을 지원한다. 추가 26개는 날짜·인증번호·주소 등 서비스별 입력을 받는다. 결정례 상세와 재해사례 첨부목록도 연결했다. 연결 체크의 예제 입력은 실제 검색에 자동 적용하지 않는다. [사용 방법과 검증 범위](additional-api-search.md)를 참고한다.

## 사용 순서

1. 일반 Windows 사용자로 로컬 앱 `http://127.0.0.1:4317/` 실행.
2. **연결 설정 → 공공데이터 API 연결**에서 서비스별 일반 인증키를 입력하고 **보호 저장**. Encoding/Decoding 둘 다 입력 가능하며 URL 전체는 불가.
3. 저장·재읽기 성공과 **연결 시험** 성공을 구분한다. 연결 시험은 공개 예시 검색 한 번이며, 상세·원문 완전성 검증을 뜻하지 않는다.
4. **공공자료 조회**에서 서비스·검색 구분·검색어 선택. 입력 검색어만 해당 API로 전송하며 자연어 업무 질문 전체는 전송하지 않는다.
5. QnA·MSDS·위험물 목록은 상세 확인. 필요한 응답을 **자료함에 저장**한다.
6. 자료함에서 원문·조건·날짜를 대조하고 **새 법규 검토**에 문서를 선택한다. 기존 모델 전송 동의가 적용된다. 자료함 확인은 법적 근거 승인과 다르다.

## 보존·오류 처리

- 키는 Windows DPAPI 암호문으로만 영구 저장. 일반 DB, 백업, 로그, 공개 Git 데이터에 넣지 않는다. 세션 한정 실행은 화면에서 표시하고 재시작 시 키가 사라진다.
- 저장 직후 보호 저장소 재읽기 검사. 실제 사용자 키의 재시작 후 유지·실서비스 연결은 키를 입력한 뒤 별도로 검증해야 한다.
- HTTP 오류, 게이트웨이 XML 오류, JSON/XML 스키마 변화, 시간 초과를 0건과 구분. 제공기관 오류 원문·키 포함 URL은 반환하지 않는다.
- 요청당 20초/4MB 제한, 리디렉션 차단, DTD/엔티티 선언 차단. MSDS 상세는 4개씩 최대 16회 호출하며 일부 실패는 누락 항목으로 남긴다. 자동 재시도·예약수집은 하지 않는다.
- 조회 결과 캐시는 30분/100건 제한. 서버 재시작·키 변경 시 다시 검색. 저장 버튼은 서버가 보유한 응답 ID만 받는다.
- 저장 자료는 조회 시각, 검색 조건, 공식 안내 주소, 인증값 없는 호출 경로, 응답 필드, 본문 SHA-256을 가진 TXT 원본으로 자료함에 보관. 기존 비공개 백업·복원에 포함된다.
- 조회일을 법령 시행일 또는 회신일로 간주하지 않는다. `regDate`는 원 응답 필드 그대로 보존하며 회신일 자동 추론을 하지 않는다.
- 수집자료는 기본 미확인 상태. 법령 evidence 또는 승인된 결정 규칙으로 자동 승격하지 않는다. 물질·질의응답·기술지침만으로 `clear_risk` 판정하지 않는다.
- 현재는 **검색·선택 첨부 방식**이다. 자연어 질의에서 여섯 API를 자동으로 계획·호출하는 기능, 전량 수집, GUIDE 본문 자동 다운로드, 법제처 조항 자동 연결은 아직 구현 범위에 포함되지 않는다.

## 검증

2026-10-07 발급 키를 이용한 실제 검증에서 6개 서비스의 정상 응답 및 Windows DPAPI 저장값의 서버 재시작 후 재읽기를 확인했다. 공개 QnA는 ‘위험물’ 검색 11건 중 첫 항목의 질의·답변 본문, 소방청은 CAS `67-56-1` 상세 59개 필드, MSDS는 CAS `71-43-2` 상세 16항목, 환경공단은 같은 CAS의 지정 유형·함량·예외 필드, GUIDE는 ‘작업환경측정’ 검색 목록과 파일 링크를 확인했다. 이 결과는 표본 연결 검증이며 전체 자료의 법적 완전성 검증이 아니다.

실제 응답으로 보완한 처리:

- 소방청 CAS 상세 응답은 `body.item`만 있고 `totalCount`가 없을 수 있다. 상세 연산에 한해서 반환 항목 수를 사용한다. 목록 응답의 전체 건수 누락은 계속 오류로 처리한다.
- 환경공단은 본문 헤더의 정상 코드로 `200`을 반환한다. 이 코드는 환경공단에 한해서 허용한다.
- 스마트검색 전체 분류는 각 분류를 따로 페이지 처리한다. ‘사다리’의 전체 363건에서 첫 페이지 35건, 둘째 페이지 24건이 반환되는 것을 확인했다. 마지막 페이지는 합계가 아닌 분류별 최대 건수로 계산한다. 응답 `pageNo`는 0부터 시작하지만 요청과 화면은 1부터 시작한다.

- `npm run check`: 서비스별 공식 규격 fixture, 키 인코딩/노출 방지, 0건/오류 구분, 상세 동일성, MSDS 부분 실패, CSRF, 참고문서 저장·백업 복원.
- `npm run test:e2e`: 격리된 `SHE_DATA_DIR` 서버의 기존 업무 흐름.
- `npm run test:e2e:public`: 자체 격리 서버, 합성 응답·가짜 키만 사용. 6개 키 저장/연결 시험 → QnA 상세 → 자료함 → 검토 첨부, 모바일 레이아웃.
- 위 시험 통과는 실제 발급 키의 이용 승인·기관 응답 검증을 대체하지 않는다.
