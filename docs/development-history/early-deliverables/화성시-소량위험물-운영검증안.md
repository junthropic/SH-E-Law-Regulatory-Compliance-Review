# 화성시 소량위험물 저장·취급: 다음 운영 검증

작성일: 2026-10-03 (한국시간). 사용자가 선택한 첫 적용 범위는 경기도 화성시 / 소량위험물 저장·취급이다. 특정 사업장의 적법 여부를 판정한 보고서는 아니며, 아래 항목의 원문 대조·현장 사실 확인·승인은 아직 완료되지 않았다. 이 문서는 로컬 작업 자료로 보관한다.

## 1. 연결 유지 검증 — 완료

- Windows DPAPI 모드에서 로그아웃 없이 서버를 정상 종료하고 새로운 프로세스로 시작했다. 프로세스 ID는 34656 → 44224로 변경됐다.
- 재로그인·OC 재입력 없이 OC 설정과 ChatGPT 연결이 유지됐으며 기존 검토 2건의 ID가 보존됐다.
- 재시작 후 실제 ChatGPT 모델 목록 5개 조회 성공. 저장된 사용자 OC로 Korean Law MCP 4.15.5의 경기도 위험물 조례 검색 성공.
- 가상 사례 `5d9683dd-4a2f-48fc-a210-595ade27f527`을 실제 gpt-5.6-luna로 분석했다. 15:34:39 시작, 15:36:44 완료, 약 125초. 사람 판단 필요 1건·추가 자료 필요 5건·명확한 리스크 0건. 경기도 조례와 위험물안전관리법·시행령·시행규칙이 근거 목록 앞부분에 포함됐다.
- 법규를 재수집하지 않고 최근 성공 자료를 사용했으며 실제 확인 시각을 유지했다. 이번 시험은 앱 프로세스 재시작 검증이다. PC 전체 재부팅과 실제 토큰 만료 시점의 장기 운용을 시험했다고 표시하지 않는다.
- 로그인 상태는 유지했다. 앱 화면은 새로고침하면 된다. 인증값·토큰은 기록에 포함하지 않는다.

## 2. 국민신문고: 공식 API를 우선 연결

기존 안내를 구체화한다. 웹페이지 자동 수집과 공공데이터포털 API 이용은 별도 경로다. 공개 사례에는 [국민권익위원회 민원정책 질의응답조회서비스](https://www.data.go.kr/data/15074671/openapi.do)를 먼저 사용한다. 2026-10-03 확인한 포털 안내상 무료, 개발·운영 자동승인, 개발계정 트래픽 10,000건, 이용허락범위 제한 없음으로 표시된다. 목록과 QnA 번호 기반 상세 조회가 안내돼 있다. 실제 제공 범위·첨부 포함 여부·빈 응답은 키 발급 후 검증해야 한다.

사용자가 할 일:

1. 위 서비스의 **활용신청**에서 실제 목적을 적어 신청하고 승인 상태를 확인한다. 목적 예: “사업장 환경·안전·보건 법규 검토를 위한 공개 질의응답 검색, 관련 법령 원문과 연결하여 참고자료 제공”. 상업적 제공 계획이 있다면 그 사실도 기재한다.
2. 발급되는 `serviceKey`는 법제처 `OC`와 다르다. 현재 앱의 OC 입력란에 넣지 않는다. 값은 채팅·Git에 올리지 않고, 신청·발급 완료 여부만 알려준다.

개발 후 확인할 일:

- API 전용 암호화 설정과 목록·상세 수집기를 구현하고, 위험물·저장·취급 키워드로 소수 사례를 시험한다. 현재 앱에는 이 API 어댑터와 입력란이 아직 없다.
- 질의 원문·답변 원문·처리기관·등록일/회신일의 차이·원문 번호·출처·수집시각을 구분해서 보관한다. API에 없는 필드를 추정하지 않는다.
- 관련성이 있는 공개 회신만 검색 근거로 제시하고, 회신이 전제한 사실과 현재 사업장 사실이 다르면 사람 검토로 보낸다. 과거 회신의 인용 법령도 기준일에 맞춰 재확인한다.
- 공개 API 결과가 국민신문고 전체 또는 본인 비공개 민원의 전량이라고 간주하지 않는다. Git 공개 내보내기는 별도 출처·개인정보 검사를 구현하기 전까지 현재 허용 목록을 유지한다.

본인 민원 자동 수집 등 웹 접근이 꼭 필요한 범위는 운영기관에 별도로 문의한다. [국민신문고 이용약관 제12조 제6항](https://www.epeople.go.kr/nep/gdnc/TermsConditions.npaid)은 사전 승낙 없는 기술적 자동 접근·수집을 제한한다. 공식 API 활용 승인만으로 웹 자동 로그인의 승낙까지 받았다고 처리하지 않는다. 그동안에는 보유 회신을 자료함에 올릴 수 있다.

아래는 **미발송 문의 초안**이다. 운영기관 고객문의로 제출할 수 있다.

> 사업장 환경·안전·보건 검토 도구에서 위험물 관련 공개 질의응답을 원문 출처와 연결하려고 합니다. 민원정책 질의응답조회서비스의 공개 범위, 답변 전문·첨부 제공 여부, 저장·검색 및 LLM 분석 허용 조건을 안내해 주십시오. API에 포함되지 않는 본인 민원은 별도 자동 수집을 검토 중이며, 허용 여부와 신청 절차, 대상 URL·인증 방식·수집 주기·저장기간·재배포 조건에 대한 서면 안내를 요청합니다. 실제 운용 목적·대상·규모는 신청 시 구체적으로 기재하겠습니다.

## 3. 화성시 검증용 원문 묶음

기준 문서 후보는 [경기도 위험물안전관리 조례, 2024-03-20 시행·제7945호](https://www.law.go.kr/LSW/ordinInfoP.do?ordinSeq=1914049), 위험물안전관리법·시행령·시행규칙이다. 2026-10-03 수집 데이터 및 공개 열람의 버전 표시는 확인했으나 개별 공보·별표·경과조치의 완전성 승인은 하지 않았다.

| 검토 묶음 | 확인할 내용 | 결과로 남길 것 |
| --- | --- | --- |
| 도 조례와 공보 | 조례 공포번호·공포일·시행일, 개정 전후 전문, 시행 유예·경과조치 | 공보 파일과 해당 쪽, 버전별 조문 대응표 |
| 국가법과 별표 | 위험물 분류·지정수량, 합산 기준, 관련 시설·소화 기준의 별표 | 원본 파일, 표의 행·열·단위, 추출문과 원본의 차이 |
| 도 조례 제2·3조 | 지정수량 미만 일반 기준과 소량위험물 추가 기준의 적용 구간 | 경계값 사례와 필요한 사실 목록 |
| 도 조례 제4~10조 | 옥내·옥외·탱크 종류 및 물질별로 적용되는 기준 | 시설 종류별 적용/제외 근거 |
| 도 조례 제12조 등 예외 | 관할 기관의 인정이 필요한 특례, 개별 단서·제외 조건 | 예외 요건과 실제 인정 문서 유무 |
| 화성시 관련 규정·관할 | 실제 주소에 따른 소방서 관할, 시 규정·도시계획·건축 등 관련 위임사항 존재 여부 | 조회 범위·출처·검색일·미확인 사항 |

경기도 조례가 핵심이지만 별도의 “화성시 소량위험물 조례”가 반드시 존재한다고 가정하지 않는다. 시보·자치법규와 관련 규정을 확인한 근거를 남긴다. 화성소방서 또는 동탄소방서 등 실제 관할은 상세 주소를 기준으로 확인한다. 입법예고·의회 개정안은 공포된 조례와 구분한다.

소량위험물 구간의 경계는 조례 제3조의 지정수량 5분의 1 이상~지정수량 미만을 원문 대조 대상으로 삼는다. 물질 분류·지정수량·동일 장소 합산·해당 시점이 확인되기 전에는 리터 수만으로 의무를 확정하지 않는다. 조례 제12조와 같이 기관 판단이 필요한 특례는 AI나 검토자의 내부 승인으로 대체하지 않는다.

## 5. 전문가 규칙 승인: 내부 품질 관리 절차

앱의 “승인”은 법정 인허가나 정부의 유권해석 발급이 아니다. 코드를 통과시키기 위해 미확인 항목을 모두 true로 바꾸지 않는다.

권장 역할은 현장 담당자의 사실 확인 → 해당 분야 경험이 있는 검토자의 원문·적용요건 확인 → 필요한 쟁점만 관할기관 질의 또는 법률 검토다. AI는 근거 정리와 규칙 초안·시험 사례를 준비하고 승인자의 이름을 대신 기재하지 않는다.

첫 승인 후보는 적용 범위가 좁고 증빙 가능한 규칙 3~5개로 제한한다. 각 후보에는 법규 버전·조항·원문 인용·필수 사실·예외·단위·판정 결과·검토자·승인일을 기록한다. 수량 계산 결과를 바로 “위반”으로 바꾸지 말고 적용 구간 분류와 의무 위반 판단을 구분한다.

권장 회귀 사례:

1. 지정수량 배수 경계의 직전·동일·직후 — 0.2 및 1 경계.
2. 복수 물질과 서로 다른 구역의 합산 여부가 확인된 경우/미확인인 경우.
3. 옥내·옥외·탱크 종류가 서로 다른 경우.
4. 기존 시설과 개정 후 신설 시설, 설치일이 미확인인 경우.
5. 특례 인정 문서가 있는 경우와 주장만 있는 경우.
6. SDS·단위·최대 수량·허가 사실 중 하나라도 빠진 경우.

현재 규칙 엔진은 단일 비교 조건을 지원한다. 복합 조건·예외를 충분히 표현하지 못하면 엔진 개선과 시험이 선행돼야 하며, 그동안은 사람 판단 필요로 유지한다. 검토자는 완료한 원문 대조 범위와 실제 규칙만 앱의 확인서 등록 경로로 승인한다. 현재 실제 승인 규칙은 0개다.

## 6. 진행 순서와 완료 기준

| 순서 | 다음 행동 | 완료 기준 |
| --- | --- | --- |
| 1 | 공식 질의응답 API 활용신청 | 해당 API 승인·키 발급 확인, 값은 별도 보호 저장 |
| 2 | 화성시 현장 자료와 원문 묶음 확보 | 물질·수량·시설·날짜·관할 및 공보·별표의 미확인 목록 작성 |
| 3 | 수집기·대조 화면·승인 초안 보완 | 문서마다 출처·기준일·해시·누락·변경 여부 확인 가능 |
| 4 | 3~5개 규칙과 경계 사례 검토 | 적용·제외·추가자료 사례가 승인된 기대 결과와 일치 |
| 5 | 검토자가 승인하고 제한 운영 | 승인 범위에서만 확정 분류 허용, 변경 시 승인 효력 재검사 |

추천 우선순위는 **공식 API 신청과 현장 자료 준비를 함께 진행하고, 화성시 소량위험물 범위의 원문 대조를 먼저 완성하는 것**이다. 국민신문고 웹 수집 승낙 대기 때문에 법령·조례 검증까지 멈출 필요는 없다.
