## 추가로 수정한 문제

인증을 제거하면 열리지 않던 API 원문 링크를 공개 버전 열람 주소로 바꿨습니다. 조례의 실제 폐지 필드, 9999년 시행일의 불확실성, API 별표 제공 제한을 반영했습니다. 원문·메타데이터는 생략하지 않고 gzip 공개 번들로 보관하며 다운로드·압축 해제 크기 한도를 검사합니다.

매 검토마다 전체 연혁을 다시 수집하던 지연도 수정했습니다. 국가법과 해당 지역 모두 최근 24시간 내 수집 성공한 자료만 재사용하고 결과에는 실제 확인 시각을 표시합니다. 실패·만료된 출처는 다시 확인하며 사용자가 '지금 갱신'을 실행할 수 있습니다.

실제 225개 원문을 보관한 최신 앱에서 자료 확인 검토는 0.82초에 완료됐고 경기도 조례 및 위험물안전관리법·시행령·시행규칙이 우선 선택됐습니다. 이는 AI 추론을 제외한 측정값입니다. 검색색인의 불필요한 재생성과 전체 DB 반복 읽기도 제거했습니다.
