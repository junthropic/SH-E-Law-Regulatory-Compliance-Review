# 소유자가 요청한 임시 API 키 보관

2026-10-09 저장소 소유자의 명시적 요청에 따라 비공개 저장소 루트의 `.env.api-keys`에 현재 보호 저장소에서 읽은 공공 API 32개 항목과 법제처 OC 1개를 보관했습니다. 서비스별 주석과 `SHE_API_KEY_<서비스 ID 대문자, 하이픈은 밑줄>` 변수로 연결합니다. 같은 인증값을 공유하는 서비스도 등록부의 32개 항목을 각각 유지합니다.

이 파일은 **평문**입니다. 비공개 저장소의 접근 권한자는 내용을 읽을 수 있고, 파일을 나중에 삭제하는 커밋만으로 이전 Git 이력에서 사라지지 않습니다. 이력에서도 없애려면 별도 이력 정리와 기존 복제본 처리 또는 키 재발급이 필요합니다. 이번 작업은 사용자가 직접 삭제하겠다는 요청에 따라 파일을 보관하며 자동 삭제·키 변경을 수행하지 않습니다.

ChatGPT/OAuth/GitHub 로그인 토큰, 민원, 업무자료, 개인 DB와 백업은 포함하지 않았습니다. `.local`의 보호 저장 인증값도 변경하지 않았습니다. 키 값은 대화나 작업 로그에 출력하지 않았습니다.

현재 앱은 `.env.api-keys`를 자동으로 읽지 않습니다. `LAW_OC`는 기존 환경 변수 이름이며 나머지 `SHE_API_KEY_*`는 이번 보관용 이름입니다. 환경 파일을 읽기만 해도 기존 32개 API 연결 설정으로 자동 복원되는 기능은 구현하지 않았습니다. 운영 앱·UI·기능·API 호출·재시작은 변경하지 않았습니다.

이 파일만 소유자 요청의 예외로 Git 제외 규칙을 우회하여 추가했습니다. 다른 `.env`·`.local`·개인 업무자료의 제외 규칙은 유지합니다. 초기 업로드의 파일 manifest는 이전 커밋의 기록으로 보존하며 인증값을 포함하도록 다시 생성하지 않았습니다.
