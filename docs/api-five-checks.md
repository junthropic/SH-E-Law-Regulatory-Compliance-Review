## 확정 범위와 남은 조건

- 표의 입력·연결·실패 처리는 현재 코드와 테스트로 확인했다. 기관별 계정의 정확한 일일 잔여 한도·승인 만료일은 이 앱의 응답만으로 확인할 수 없다. 계정 관리 화면의 실제 값을 따르며 임의 숫자를 등록하지 않았다.
- CAS 직접 대조는 일치·불일치·식별자 미확보를 저장한다. 일치해도 실제 혼합물·농도·물성 또는 법적 적용이 확인된 것은 아니다. 업체·설비·허가자료가 없는 현재 상태에서는 동일 업체·제품이라고 자동 확정하지 않는다.
- 업무별 법령 원문 수집과 공공자료 조회는 별개다. 이전에 삭제 요청한 사실 추출 화면을 복원하지 않았으며, 32개 전체를 모든 질문마다 호출하지 않는다. 식별정보가 필요한 조회는 공공자료 조회에서 수행한다.
- 상세·첨부 제공 여부가 없는 서비스는 목록 후보에 머문다. 검색 응답 성공을 본문·별표·적용 조건 전체 확인으로 표시하지 않는다. 인증값은 결과 URL·로그·보고서에 저장하지 않는다.
