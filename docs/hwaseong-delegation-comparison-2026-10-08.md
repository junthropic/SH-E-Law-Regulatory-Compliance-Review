# 화성시 공포 원본·현행 위임 규정 대조 결과

기준일 2026-10-08. 실제 사업장 적합성 판정이 아니라 공식 문서 간 대조 결과다. UI·UX 변경 없음.

## 완료한 대조 범위

전체 시보 파일 234쪽·244쪽·242쪽의 텍스트를 추출·검색해 해당 문서의 시작과 끝을 확인했다. 전수 대조는 위 표에 선언한 현행 위임 조례·규칙의 본문·별표 전체를 뜻한다. 모든 연도의 모든 시보, 시보에 실린 무관한 공고, 모든 역사 버전의 위임사무와 인용 법령 전체에 대한 법률 적용 승인이 아니다.

후속 정정·관련 공보 검색은 사이트 색인 전체 페이지까지 확인했다: ‘사무위임’25건, ‘정정’156건, ‘사무위임 정정’5건. 다만 ‘사무위임’ 결과의 최신 글이 2022년이며 이미 확보한 2025·2026년 공포본도 누락된다. 따라서 색인 결과 전수 확인을 공보 첨부 본문 전체 검색이나 후속 정정 부존재 증명으로 바꾸지 않는다. 현재 비교는 날짜로 직접 확보한 원본과 당일 현행 API 목록에 근거한다. 모든 기간의 공보·정정 첨부 전체를 대조한 상태는 아니다. 검색 결과 전체와 URL은 `work/delegation-comparison/indexed-search-complete.json`에 보관했다.

비교에 제외한 것은 공백·줄바꿈, Markdown 표 구분, 반복 표 머리글, 밑줄 태그, 시각 확인한 글머리표와 가운데점 표시 차이다. 숫자·단위·조문번호·괄호·범위·예외 문언을 지워서 일치시킨 것이 아니다. 처음 불일치한 7개 셀은 공포본 8·16·17·178쪽에서 글머리표임을 시각 확인했다. EHS 주요 행은 조례 공포본 28–32쪽, 규칙 공포본 176–178쪽의 표 머리글·권한·예외·인용 조문을 시각 확인했다. 추출문 전수 일치와 모든 표 셀의 전문가 승인은 구분한다.

## 출처 불일치를 좁힌 결과

2026-10-08 재조회한 법령정보 API 응답은 이전 수집 JSON과 동일하며 현행 목록도 위 두 일련번호를 가리켰다. 따라서 이번 로컬 수집 과정에서 번호를 새로 잘못 바꾼 것은 아니다.

| 문서 | API 표시 | 공포 원문·부칙에서 확인한 값 | 판단 |
|---|---|---|---|
| 조례 2048299 | 제2412호, 일부개정, 2025-12-31 공포, 2026-02-01 시행 | 제2509호, 전부개정, 2025-12-31 공포, 2026-02-01 시행 | 공포번호·개정 구분의 출처 정보 불일치. 본문·별표 전체 추출문은 공포본과 일치 |
| 규칙 2048313 | 제784호, 일부개정, 2026-01-13 공포, 2026-02-01 시행 | 제784호, 전부개정, 2026-01-13 공포, 2026-02-01 시행 | 개정 구분의 출처 정보 불일치. 본문·별표 전체 추출문은 공포본과 일치 |

원문 API 값은 보존한다. 정규화 후보는 조례 `제2509호·전부개정`, 규칙 `제784호·전부개정`이며 근거는 각 공포문·부칙이다. 기관 내부 등록·연계 과정의 원인과 정정 완료 여부는 확인되지 않았다. 기관에 정정 요청을 자동 전송하지 않았다. 운영 DB의 원문을 덮어쓰거나 검토자 승인을 임의 생성하지 않았다.

이 불일치를 본문 전체 불일치로 확대해서는 안 된다. 다만 문서 버전 식별에 영향을 주므로 출처 정보의 차이와 정규화 근거는 보존해야 한다.

## EHS 위임 검토에서 확인한 경계

- 조례 별표1은 시장→구청장 위임이다. 기후환경정책과의 특정공사·비산먼지·휘발성유기화합물·석면 관련 사무, 신재생에너지과의 고압가스 등, 물환경생태과의 토양·가축분뇨 관련 사무, 자원순환과의 사업장폐기물 배출자 신고·지도, 환경지도과의 소음·악취·폐기물 배출자 지도 등은 각각 독립된 행과 근거를 갖는다.
- 조례의 ‘생활악취 민원처리’에는 대기·폐수·악취·폐기물 관련 업 인허가 사업장 제외 문구가 있다. 이를 모든 악취 업무의 구청장 권한이라고 확장할 수 없다.
- 규칙 별표1은 시장이 받은 권한을 구청장에게 재위임하는 표다. 공회전, 환경개선부담금, 빛공해, 전기안전·전기공사·전력기술·승강기 등 각 행의 범위가 다르다.
- 전기안전 기술기준 적합명령에는 전압 10만 볼트 미만의 수용설비와 설비용량 1만 킬로와트 미만 발전설비라는 조건이 있다. 이 조건을 다른 위임 행까지 공통 적용하지 않는다.
- 위 시 조례·규칙 전체 추출문에서 위험물 저장·취급 권한을 화성시장·구청장에게 일괄 부여하는 근거는 발견하지 못했다. 이것만으로 위험물 의무가 없다고 결론내리지 않는다. 경기도 위험물안전관리 조례 제11조의 임시저장·취급 승인 및 별지1·2호는 관할 소방서장 경로이며, 소량 위험물의 일반 저장·취급과 임시저장 승인은 구분한다.
- 특정 사업장의 담당 소방서·구청·부서는 주소, 대상 행위와 해당 법정 권한을 연결해야 한다. 실제 사업장 주소가 없으므로 이를 확정하지 않았다.

## 산출물과 재현

- `work/delegation-comparison/화성시 사무위임 조례.json`, `화성시 사무위임 규칙.json`: 행·셀·본문 대조, 페이지, 파일 해시.
- `work/delegation-comparison/fresh-check.json`: 현행 목록과 재조회 응답의 동일성.
- `work/city-gazette/delegation-gazettes.json`: 게시물·첨부 URL, 원본·압축 해시, 수집 시각.
- `work/compare-delegation.py`: 전체 추출문과 행·셀 비교 재실행 스크립트.
- 원본 PDF·HWP·API JSON은 별도 조사 공간에 보관. 기존의 전체 조사 자료 운영 import 스크립트는 실행하지 않았다.
