# 사업장 사실·원본·API·판정 재점검

## 실제 화성시 사업장 검증 여부

실제 사업장은 제공되지 않았다. 경기도 화성시는 사용자가 선택한 조회 지역이고, 보유자료도 없다고 확인했다. 이 세 가지는 상담·조회 조건이며 특정 사업장의 현장 사실을 입증하지 않는다. 물질·농도·수량·시설·작업·허가·설치일은 모두 미확인이다. 비교할 실제 입력이 없으므로 ‘충돌 없음’도 입증한 것이 아니다. 가상 사례의 시험 결과를 실제 사업장 확인으로 사용하지 않았다.

현재 구현은 사용자 답변 확인, 미확인·형식 부족, 입력 충돌 후보를 구별한다. 입력 확인은 원본 입증과 다르다. 예시·변경 전후·정정이 구분되지 않는 모든 자연어 충돌을 완벽히 탐지하는 기능은 아니다.

## 공보·시군구 범위

[경기도보 제7463호](https://www.gg.go.kr/cmmn/download.do?idx=832983)를 다시 확보하고 선택한 부칙 문구·숫자·표현을 조례와 대조했다. 공백 정규화 후 일치했고, 전체 공보·표·수치·조문별 적용의 사람 검토는 미완료다. 공보 PDF 해시: 3938da1f87be1410e14b85b20777ae8905cdeece8da5acdd41e2b8bb6ee266f9. 조례의 일반 시행 문구와 일부 조항의 6개월 지연 시행 단서를 구별한다.

화성시 소관으로 ‘위험물’을 검색한 현행 자치법규 목록은 0건이었다. 이는 다른 명칭의 위임 규정·시보·필지별 제한이 없다는 증거가 아니다. 화성시 시보 전수 대조와 개별 현장 적용은 미완료로 남긴다.

## 판정과 확대 검증

- 허가 서류 미제공·미확인·예정·추정은 확정 사실이 아니다. 허가 있음/없음과 질문/답변 값의 충돌을 판단 보류로 표시한다. 중복 사실과 미확인 허가로 규칙을 실행하지 않는다.
- AI가 명확한 리스크라고 제안해도 검토자 확인과 근거·조건 검증을 통과한 결정 규칙이 아니면 확정하지 않는다. 원문 인용이 없거나 일치하지 않는 판단은 추가 자료 필요로 분류한다.
- 개별 회신·해석만으로 현재 사업장을 판정하지 않는다. 회신일·당시 법령·관할·당사자·시설·조건을 대조할 필요를 남긴다.
- 폐기물: 폐기물 종류·분류, 수량, 수탁업체·허가 범위를 확인한다. 화학물질: CAS·함량·수량·작업·설비를 확인한다. 산업안전보건: 업종·근로자·작업·유해인자·설비 식별정보를 확인한다. 실제 시설 적합성 승인은 하지 않았다.
- 새 검토에서 폐기물·화학물질·산업안전보건 업무가 탐지되면 저장된 법제처 OC로 해당 법률·시행령·시행규칙을 수집하고 연결한다. 실패는 미확보로 남긴다. 지자체 적용 조례·별표·부칙·예외의 전수 검증 완료를 뜻하지 않는다.
