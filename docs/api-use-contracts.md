# 32개 API 사용 조건과 검증 범위

> 최신 재점검: [사실·원본·판정 점검](case-audit-2026-10-08.md), [32개 API 다섯 가지 조건](api-five-checks.md). 아래 기록은 이전 단계의 상태이며 현재 확보·미확보 상태는 최신 보고서를 따릅니다.
2026-10-08. 연결 설정과 검토자 화면은 변경하지 않았다. 아래 목록은 구현된 검색 필드에서 생성했다.

## 호출 전 검사

- 32개 모두 지원하지 않는 필터·잘못된 검색 구분·페이지 범위를 거부한다. 시험용 연결 체크의 샘플 값을 실제 업무 조회에 자동 대입하지 않는다.
- CAS 검색은 형식과 마지막 검증 숫자를 확인한다. 번호가 맞더라도 실제 제품 동일성·농도를 확정하지 않는다.
- 날짜의 존재 여부·유효 날짜·시작/종료 순서를 검사한다. 인증번호, 게시판 번호, 품목 코드 등 각 API의 식별 조건을 확인한다.
- 20초 응답 제한, 4MB 응답 제한, HTML·비정상 XML·서식 불일치 거부, 인증값 제거를 적용한다.
- 인증/활용 승인 오류, 호출 한도, 기관 오류, 통신 실패, 시간 초과를 분리한다. 인증 실패·호출 한도에 자동 반복 요청하지 않는다. 외부 기관의 장애·한도 자체를 없애는 기능은 아니다.
- 정상 0건과 실패를 구별하며, 0건을 무허가·미인증·규정 부재의 증거로 사용하지 않는다.
- 목록 조회 성공이 상세·첨부 완전성까지 보장하지 않는다. 부분 수집 실패는 확보 범위와 분리한다.

## 자동조회와 직접 조회

자동조회 계획은 현재 9개 공공 서비스와 법제처 법령·조례 조회를 이용한다. 번호·주소·품목·허가일이 필요한 나머지 서비스는 사용자 제공 식별정보로 직접 조회한다. 실제 사업장 정보가 없는 현재 상태에서 업체·설비를 임의로 만들어 호출하지 않는다. 모든 32개를 매 질문마다 일괄 호출하지 않는다.

국민신문고 개인 계정 수집은 이 목록의 공개 질의응답·결정례 API와 별개이며 이번 작업에서 활성화하지 않았다.
