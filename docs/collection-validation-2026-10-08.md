# 2026-10-08 수집·조회 보완 검증

> 최신 재점검: [사실·원본·판정 점검](case-audit-2026-10-08.md), [32개 API 다섯 가지 조건](api-five-checks.md). 아래 기록은 이전 단계의 상태이며 현재 확보·미확보 상태는 최신 보고서를 따릅니다.
## 이번 변경 범위

- 새 법규 검토의 시·도 선택에 따라 공식 기관 목록 기반 시·군·구 후보를 제공한다. 목록에 없는 지역·과거 명칭은 직접 입력할 수 있다. 시·도 변경 시 이전 시·군·구 선택을 비운다.
- 시·군·구 소관기관 코드가 확인되면 자치법규 조회의 org/sborg 조건에 사용한다. 선택하지 않은 다른 시·군·구의 조례를 검토 근거에서 제외한다. 시·도 규정과 시·군·구 규정은 함께 검토할 수 있다.
- 본문에 파일 링크가 없는 자치법규 별지는 별표·서식 목록 API로 보완한다. 관련 조례 일련번호, 시행일, 제목, 별표 식별자를 모두 대조한다. 다른 버전의 서식을 대신 연결하지 않는다.
- 공공 API의 지원 필터, 검색 구분, 날짜, CAS 검증 숫자, UN 번호 등 요청 조건을 호출 전에 검사한다. 인증·한도·기관 장애·통신·시간 초과를 구분한다.
- 법제처 HTTP 4xx에는 반복 요청하지 않으며, 네트워크 예외의 URL·인증값이 오류 메시지에 노출되지 않도록 한다.
- 연결 설정·검토자 화면의 문구·배치·버튼은 변경하지 않았다. 국민신문고 개인 계정 자동수집은 활성화하지 않았다.

## 확인 결과

- `npm run check`: 208개 테스트 통과. 사업장·자료 없음, 다른 시 조례 제외, 32개 서비스 잘못된 필터 차단, CAS 오류 사전 차단, 별지 버전 충돌 거부 등을 포함한다.
- 기본 화면, 자연어 조회, 추가 26개 서비스 조회 화면, 연결 원문 수집, 원본 대조·검토자 인계의 브라우저 검증 통과. 지역 변경 초기화와 모바일 표시 포함.
- 등록된 키로 32개 서비스 모두 실제 검색 요청 정상 응답. 고충민원 결정례 샘플은 정상 0건으로 확인했다. 이 결과는 해당 시점·샘플 조건의 조회 확인이며 모든 날짜·품목·사업장 조합이나 상세 원문의 완전성을 인증하지 않는다.
- `경기도 위험물안전관리 조례` 버전 1914049의 별지 제1·2호는 공식 목록 API의 파일 주소를 통해 원본 2개와 추출문 2개를 확보했다. 원문·표·수치를 사람이 대조해야 하므로 자동 승인 상태로 바꾸지 않았다.
- 4317에서 새 빌드 응답, 키 등록 32/32, 법제처 OC 및 ChatGPT 연결 유지 확인.
- 실제 사업장·보유자료가 없어도 일반적인 자료 조회와 추가 질문 생성은 가능하다. 실제 사실·허가 여부를 만들어내거나 실제 사업장의 위반 판정을 생성하지 않는다.

## 지역·자료의 한계

시·군·구 목록은 2026-10-08 국가법령정보센터 기관 목록의 스냅샷이다. 목록을 받지 못한 지역도 직접 입력할 수 있고, 명칭만으로 필지·용도지역·행위제한을 확정하지 않는다. 현재 명칭과 과거 기준일의 관할 변경은 별도 대조가 필요하다.

실수집 검증과 시험용 사례는 운영 DB와 분리했다. 별지 파일 확보는 수집 경로 검증이며 전문가의 법률 적용 승인이 아니다. 외부 기관의 장애·호출 한도 자체가 사라지는 것은 아니다.

백업·복원은 기존 회귀 테스트에서 문서 해시, 검토·대조 기록 보존과 승인 상태 초기화를 확인한다. API 인증정보는 개인 백업에 포함되지 않는다.
