# 선택 6개 의무와 기간·예외의 검토 계약

기준일 2026-10-08. 공식 원문 HTML/추출문과 SHA-256·수집시각은 official-sources.json 및 official/에 보관한다. 사람이 법적으로 승인한 규칙이 아니다. 아래 숫자는 확인한 조문에 대한 후보 구현의 기준이며 실제 사업장에 자동 적용하지 않는다.

|---|---|---|
| 재선임 | 위험물안전관리법 제15조②, MST259933, 시행 2025-08-07 | 대상 제조소등·관계인, 이전 선임, 해임/퇴직 사건·일자, 후임 자격·선임 사실, 별도 불이행 입증 |
| 선임 신고 | 같은 법 제15조③ | 선임 사건, 해당 신고 대상·기관·접수일, 14일 계산 profile, 신고 불이행의 독립 자료 |
| 대리 지정·대행 | 같은 법 제15조⑤ 전단 | 일시 직무불능 또는 후임 공백, 법정 자격, 지정과 실제 대행 |

원문 링크: [법 제15조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=259933&joNo=0015&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR), [법 제18조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=259933&joNo=0018&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR), [시행규칙 제68조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=287841&joNo=0068&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR), [시행규칙 제65조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=287841&joNo=0065&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR), [2021 시행본·부칙](https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=222461&efYd=20211021&chrClsCd=010202).

이번 원문 대조에서 시행규칙 제68조의 기록 내용과 보존기간을 확인했다. 보존을 일괄 3년으로 두지 않았다. 제65조의 구조안전점검 대상·기간·특례와 법 제18조의 점검결과 제출을 구분했다. 점검 대상은 [시행령 제16조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=287381&joNo=0016&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR) 원문도 확인했다. 정기검사 대상·고시상 방법·검사자 자격·모든 별표·지자체 위임까지 전수 확인한 것은 아니다.

2021 시행본의 단일 조문 endpoint는 HTTP 200이면서 조문 본문이 비어 있었다. 이를 확보로 표시하지 않고 full `lsInfoR`에서 제18조와 부칙 제1·3조를 확보했다. 빈 응답도 실패 근거로 보존한다. 개정 전 조문 전체와 모든 후속 개정 경계의 연속성 대조는 아직 미완료다.

기간 계산은 [행정기본법 제6조](https://www.law.go.kr/LSW/lsSideInfoP.do?lsiSeq=269955&joNo=0006&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR)와 민법 제155·157·159·160·161조를 함께 읽었다. 특별규정, 제출기한, 권익 제한·의무 지속기간을 일괄 동일하게 취급하지 않는다. 각 의무의 실제 profile 승인은 보류다. `LegalProfile`은 의무 성격·기산 사건·단위·초일·휴일·시간대·달력 버전·근거·검토·반복 방식·말일 종료 규칙을 분리한다.

반기·calendar-year·직전 사건 기준 rolling 기술 모델을 추가했으나 특정 의무의 '연 1회'를 임의로 이 중 하나에 연결하지 않았다. `due` 당일을 이미 경과했다고 출력하지 않는다. 내부 알림과 법정기한을 혼합하지 않으며 현재 internalAlert는 별도 미설정이다.

예외 engine은 비대상·특정 의무 면제·감경·간주·대체·연장·유예를 구분한다. from→to 방향, 대상, 적용기간, 조건의 입증, 법적으로 요구되는 승인, 잔존 의무를 확인한다. 감경량·연장일이 없으면 적용하지 않는다. 이 기술 모델을 모든 실제 정책에 자동 결합한 것은 아니다. AC28의 승인 부재 조건은 원문상 승인 요건이 있는 예외에만 적용한다.

선택 정책의 현재 상태는 실행 가능한 후보·원문 부분 대조·독립된 자동 시험 실행·분야 검토 대기이다. 시험 작성자가 제공한 synthetic fixture를 독립 전문가의 정답 자료로 부르지 않는다. 실제 승인 0개, 운영 활성화 0개다. 나머지 37개 후보도 policy-contracts.json에 유지한다.
