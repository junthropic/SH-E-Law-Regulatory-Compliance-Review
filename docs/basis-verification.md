# 근거별 검증

> 최신 재점검: [사실·원본·판정 점검](case-audit-2026-10-08.md), [32개 API 다섯 가지 조건](api-five-checks.md). 아래 기록은 이전 단계의 상태이며 현재 확보·미확보 상태는 최신 보고서를 따릅니다.
새 검토 결과의 **근거별 검증**에서 기준일·시행 기간, 전문, 별표·서식, 연혁·부칙, 예외·위임, 갱신 시각을 확인합니다. 국가법·시도 조례 수집 여부와 공보·시군구 대조 승인도 별도로 표시합니다.

- 법규 원문에 `「법규명」`으로 명시된 참조와 확보한 근거의 제목을 연결합니다. 공백만 정규화하며 법률과 시행령을 혼동하거나 약칭을 임의 해석하지 않습니다. 후보 연결은 해당 조항이 적용된다는 승인이 아닙니다.
- 연결 원문 누락·동일 제목의 복수 후보·표시 한도·미래 기준일은 미확인 범위에 반영합니다. 기존 규칙 승인 게이트에도 적용되며 미확인 자료가 있는 검토를 명확한 리스크로 승격하지 않습니다.
- 별표·서식, 부칙·경과조치·시행 특례, 예외·단서, 위임·준용 표현의 정확한 원문 발췌와 위치를 저장합니다. 표현이 없더라도 해당 규정이 없다고 확정하지 않습니다.
- 한 근거당 연결 법규 100개, 각 표현 유형별 15개까지 표시하고 전체 탐지 수를 함께 기록합니다. 발췌가 문장 중간에서 잘릴 수 있어 적용 판단 시 저장된 전문을 대조해야 합니다.
- 긴 본문의 뒤쪽에서 탐지된 발췌를 AI 문맥에 일부 포함합니다. 근거당 본문·발췌 합계 18,000자, 전체 90,000자 한도를 유지합니다. 생략된 본문은 계속 미확인 범위로 표시합니다. 외부 AI 전송은 기존 사용자 동의 흐름을 따릅니다.
- 결과 JSON과 Markdown에 검증 기록을 보존합니다. 기존 검토는 당시 기록을 유지하며 새 검토부터 검증표를 생성합니다. 원문 변경 뒤에는 새 검토가 필요합니다.

이 기능은 저장된 근거에 대한 구조 검사·검토 위치 안내입니다. 누락 법규 자동 전수 수집, 공보 자동 대조, 별표 표·수치의 정확성 판단, 예외의 사업장 적용 판단, 전문가 승인까지 자동 완료하지 않습니다. 원문 수집의 완전성과 법적 판단을 구분합니다.

## 연결 원문 수집·재검토

완료된 검토의 누락 법규 옆 **원문 수집·재검토**를 누르면 저장된 OC로 법제처 목록·전문을 조회합니다. 국법은 시행일 기준 현행·연혁 목록, 조례는 현행·연혁 목록을 검색합니다. 국법에 정확한 제목이 없으면 행정규칙 목록을 조회합니다. 행정규칙의 전체 연혁과 명칭 변경까지 확보했다는 의미는 아닙니다.

제목은 공백만 정규화하며, 지역·기준일·식별자·상세 본문의 시행일을 대조합니다. 폐지된 최신 버전 대신 과거 버전을 되살리지 않습니다. 동명 법규와 버전 충돌은 보류합니다. 시군구 조례는 해당 시군구명과 시도 소관 정보를 함께 확인하며, 확인할 수 없는 경우 연결을 확정하지 않습니다.

선택한 법규 한 개를 수집해 **새 검토**를 만듭니다. 새 원문이 참조하는 다른 법규까지 자동으로 연쇄 수집하지 않습니다. 원문은 검토별로 지역·시군구·기준일에 묶어 보관하고 다른 검토의 공통 근거 DB에 자동 편입하지 않습니다. 추가 답변으로 재검토할 때 연결 ID를 유지하며, 원문 최신성·별표·공보·예외 검증은 계속 별도 표시합니다.

AI는 기본적으로 다시 실행하지 않습니다. AI 분석을 사용했던 검토에서는 추가 원문과 질문·선택 자료 전송에 체크한 경우에만 기존 모델로 재분석합니다. 원문 수집 실패 시 이유 또는 기관 응답 확인 안내를 표시하고 이전 검토로 돌아갈 수 있습니다. 조회별 최대 3페이지, 수집 통신 180초, 검토별 연결 원문 30개로 제한하며 한도 초과를 수집 성공으로 표시하지 않습니다.

원문·첨부는 `.local`에 저장됩니다. 일반 백업의 검토 근거에도 연결 원문이 포함되므로 복원 후 새 검토에서 재사용할 수 있으며, 복원된 검증 승인은 초기화합니다. 원본 첨부 바이너리는 기존 백업 범위에 포함되지 않아 필요하면 다시 수집해야 합니다.

검증: 기준일·갱신 경계, 원문 후보 혼동 방지, 미확보·충돌 전파, 정확한 발췌, AI 문맥 한도 및 뒤쪽 부칙 포함, 저장·내보내기 단위시험. 격리 브라우저 시험으로 원문 후보 열기, 검토 기록 유지, 모바일을 확인합니다. 실제 사업장의 법률 적합성 승인 시험과 구분합니다.
