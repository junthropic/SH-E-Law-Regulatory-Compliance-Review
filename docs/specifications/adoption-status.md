## A07 정책 선택

문서의 1→2→4초는 예시다. 사용자가 느린 응답을 허용하도록 지시했으므로 A07은 요청당 60초, 최대 2회(최초+1회), 5~7초 재시도 대기, 동일 서비스 완료 후 최소 2초 간격을 선택했다. 다른 API는 기존 20초를 유지한다. 인증·요청·형식 오류는 자동 재시도하지 않는다. 호출 한도 응답은 재호출 유예하고 Retry-After를 우선 존중한다. 제공기관의 정확한 초당 허용량 및 사용자 계정 잔여량을 추정하지 않는다. 기관 장애나 차단 가능성의 0%를 보증하지 않는다.

## 추가 지시 반영: 사실·판정 로직 1차 보완 (2026-10-08)

- 새 검토의 사용자 답변은 사용자 진술로, 모델 추출은 모델 제안으로 기록한다. 기존 `confirmed`는 입력 완결성의 호환 필드이며 객관 검증의 증거로 사용하지 않는다. 지역·기준일 선택도 실제 사업장 확인으로 취급하지 않는다. 문서 추출문 확인 버튼으로 현장 사실 검증 상태를 올리지 않는다.
- 사실별 진술 출처·진술 여부·검증 상태·증빙 ID·충돌 ID·기록 시각을 분리했다. 대상·산정 기준·범위·유효 기간은 확인되지 않은 값을 만들어 채우지 않는다. 기존 자연어 입력에서 이 구조를 모두 자동 확정하는 기능은 아직 없다.
- 구조화된 값은 동일 대상·사실 항목·산정 기준·범위 및 겹치는 기간에만 충돌 판정을 한다. 유효 기간은 시작 포함·끝 제외다. 다른 탱크/허가량과 재고량/변경 전후는 다른 문맥으로 구분한다. 문맥을 모르는 자유문장 값 차이는 추가 확인이며, 사용자가 명시한 불일치는 별도로 남긴다.
- 수량 비교는 십진수 문자열을 정수 분수로 비교해 정밀도를 보존한다. 리터·밀리리터 및 질량 단위 환산을 지원하고, 밀도 없이 질량과 부피를 비교하지 않는다. 이 변경은 사실 비교와 규칙 문턱값 비교에 적용한다. 기존 계산기 전체의 정확 분수 산술 전환까지 완료한 것은 아니다.
- 기존 규칙은 수량 조건만 검사하며 실제 의무 불이행·적용 대상·기한의 독립 입증 정책이 없다. 따라서 일치하더라도 실무자 검토 대상으로 남기고 기존 결론 문자열을 확정 판단으로 출력하지 않는다. 명확한 리스크를 다시 허용하려면 의무별 입증 정책, 적용·기한·예외 게이트와 승인 흐름을 구현해야 한다.
- 허가·신고·교육·검사·선임 자료의 미제공/미제출/미업로드/조회 0건/통신 실패를 불이행 사실로 승격하지 않는다. 증빙이 없는 답변은 검토 결과의 추가 확인 범위에 한국어로 남긴다.
- 사실 값·단위·검증 상태·증빙 연결·충돌·대상·범위·유효 기간을 검토 재사용 해시에 포함한다. 백업 복원은 사용자 진술을 보존하되 객관 검증 상태를 미확인으로 초기화한다. 기존 저장 결과를 일괄 다시 쓰거나 실제 사업장 승인을 생성하지 않았다.
