# 화학물질 EHS 판정: 증빙자료·공식 API·업데이트·자동 갱신 기준

**API는 있습니다. 다만 하나의 API로 전부 확정할 수는 없습니다.**

권장 기준은 **① 실제 제품의 공급자 자료 ② 공공 물질정보 ③ 기준일의 법령·고시 ④ 사업장 재고·시설 자료**를 결합하는 방식입니다.

아래는 **국내 위험물·유해화학물질 EHS 판정 기준**, **2026-10-08 확인 기준**입니다. API는 공개 명세를 확인했으며, 인증키를 사용한 실제 응답 테스트까지 한 것은 아닙니다.

## 1. 항목별로 무엇을 기준으로 삼을까?

안전보건공단도 실제 유통 제품의 MSDS는 공급자로부터 받아야 하며, 공단 자료는 작성·검토용 참고자료라고 명시합니다. [출처 1, 2]

| 확인 항목 | 우선 증빙 | 프로그램 처리 기준 |
| --- | --- | --- |
| 제품 동일성 | 공급자·제조사, 제품코드·등급, MSDS 1·16항목. 제출번호, 개정일·판, 적용 제품 확인 | CAS만 같다고 동일 제품으로 병합하지 않음 |
| 혼합물·농도 | 제품 MSDS 3항목, 조성확인서·규격서. 필요시 해당 로트의 분석성적서 | 중량%·부피% 구분. 범위가 기준선을 걸치면 보류 |
| 인화점 | 제품 MSDS 9항목, 제품 시험성적서. 시험방법·개방식/밀폐식·시험 조건 확인 | 혼합물에 순물질 값을 그대로 적용하지 않음 |
| 밀도·비중 | 제품 MSDS 9항목, 규격서·시험성적서. 단위·온도·기준물질 확인 | 비중과 밀도, 증기밀도를 구분 |
| 수량·단위 | 포장 순내용량, 입고서, ERP·WMS·탱크 계측. 용기 수 × 실제 내용량 | 용기 공칭용량·총중량을 내용량으로 오인하지 않음 |
| 최대 저장량 | 허가·신고 자료, 시설 설계·운영 한도, 시점별 재고 | 허가량 / 운영 최대량 / 현재량 / 과거 최고량을 별도 저장 |
| 합산 범위 | 해당 법령, 허가 경계·배치도·공정도, 필요한 관할 확인 | 법령별 합산 그룹을 따로 관리. 회사 전체 일괄 합산 금지 |

> 권장 증빙 설계입니다. 규격서·로트 성적서도 필요한 항목이 실제 기재되어 있고 해당 제품에 적용되는 경우에만 사용합니다.

특히 **MSDS 3항목이 항상 전성분과 정확한 배합비를 공개하는 것은 아닙니다.** 함량 범위나 승인된 대체자료 때문에 판정에 필요한 정보가 부족하면, 공급자의 추가 확인을 받아야 합니다.

위험물 여부가 불명확한 경우에는 소방청 FAQ도 정확한 판정을 위해 공인 시험기관의 판정시험을 받도록 안내합니다. DB에서 검색되지 않는다는 이유로 비위험물이라고 볼 수도 없습니다. [출처 3]

## 2. 실제로 사용할 공식 자료와 API

### A. 실제 제품 MSDS: 가장 먼저 확보할 자료

- **작성·제출 책임:** 해당 물질·혼합물의 제조자 또는 수입자.
- **제출처:** 고용노동부 체계의 안전보건공단 MSDS 시스템.
- **전달 경로:** 제조·수입자 → 유통·판매자 → 구매·사용 사업장.
- **목적:** 실제 취급 제품의 유해성·위험성 및 안전취급 정보 전달.

**업데이트 시점은 정기 발행보다 ‘변경 발생’ 기준입니다.**

[MCP 확인] 현행 산업안전보건법 시행규칙 제157조는 제조·수입 **전** 전자적 제출을, 제159조는 제품명·해당 구성성분 명칭 및 함유량·유해성 및 물리적 위험성 등 정해진 사항이 변경되면 **지체 없이** 변경본 제출을 규정합니다. 산업안전보건법 제111조는 변경 MSDS를 공급망에 제공하도록 규정합니다. [법령 근거 L1, L2]

**자동 수신 방법:** 공급자에게 개정본 전달용 이메일·거래처 포털·문서 연계를 정해 달라고 요청하고, 수신 문서를 제품코드와 연결합니다. 정부 API 조회만으로 실제 납품 제품의 최신 MSDS를 받았다고 처리하면 안 됩니다.

공식 시스템:

https://msds.kosha.or.kr/

### B. KOSHA MSDS 조회 API: 일반 물질정보 보조

https://www.data.go.kr/data/15157612/openapi.do

제공기관은 한국산업안전보건공단, 관리부서는 디지털계획부입니다. 무료이며 포털상 업데이트 주기는 ‘실시간’입니다. [출처 4]

확인한 공개 명세는 다음과 같습니다.

- 목록: `getChemList001`
- 구성성분: `getChemDetail031`
- 물리·화학적 특성: `getChemDetail091`
- 기타 참고사항: `getChemDetail161`
- **개별 자료 최종수정일:** 목록의 `lastDate`
- 상세 내용은 `msdsItemNameKor`, `itemDetail` 등의 항목별 행으로 제공.

**주의:** 이 API를 제조사가 제출한 모든 제품 MSDS 원본을 내려받는 API로 보면 안 됩니다.

**자동 갱신:** 관심 물질의 `lastDate`를 비교하고, 변경 시 상세 내용을 다시 가져와 기존 값과 비교하는 방식이 적합합니다.

### C. 소방청 국가 위험물 정보 API: 위험물 분류·물성 보조

https://www.data.go.kr/data/15061055/openapi.do

API 제공기관은 소방청이며, 국가위험물통합정보시스템은 소방청 위험물소방안전과가 운영책임을, 한국소방산업기술원 위험물기술부가 운영지원을 맡습니다. 무료이고 갱신 주기는 ‘실시간’으로 표기됩니다. [출처 5, 6]

공개 상세 명세에서 확인한 주요 필드:

- `hazardmaterialclass`: 위험물안전관리법상 품명
- `flashpoint`: 인화점
- `specificgravity`: 비중
- `materialstate`: 물리적 상태
- `unno`: UN번호

목록·상세 요청은 각각 `getMaterialList`, `getMaterialInfo`입니다.

**누가 왜 올리나?** 기관이 관리하는 위험물 정보 DB를 공개하는 구조이며, 공식 FAQ는 연구개발·안전교육 등의 이용 목적과 참고자료라는 성격을 명시합니다. [출처 3] 다만 **개별 레코드의 작성자, 검토 절차, 정기 재검토 주기와 반영기한은 공개 자료에서 확인하지 못했습니다.**

**자동 갱신:** 개별 수정일 필드가 공개 명세에서 확인되지 않아, 관심 물질의 응답을 주기적으로 가져와 **내용 해시 또는 필드 차이**를 비교하는 방식이 현실적입니다.

### D. 한국환경공단 화학물질 정보 API: 규제 함량·예외 기준

https://www.data.go.kr/data/15149420/openapi.do

한국환경공단 화학물질관리처 화학물질정보부가 관리합니다. CAS·물질명·고유번호로 조회하며, 물질분류유형, 고유번호, 함량정보, 예외정보, 고시일자·고시정보를 제공합니다. 무료 REST API이고 JSON·XML을 지원하며 갱신 주기는 ‘실시간’입니다. [출처 7]

**이 API의 함량정보는 실제 제품의 배합비가 아니라, 규제 적용을 위한 함량 기준입니다.**

따라서 다음 두 값을 비교해야 합니다.

> 공급자가 증빙한 **실제 제품 함량** ↔ 공식 고시의 **규제 함량 기준**

관련 공식 검색:

https://kreach.mcee.go.kr/repwrt/mttr/kr/mttrList.do?searchKeyword=

공식 검색 안내도 염류·중금속 화합물은 개별 검색정보가 제공되지 않을 수 있어 고시내용으로 판단하라고 명시합니다. [출처 8]

**자동 갱신:** 관심 물질의 규제정보를 비교하되, 바뀐 고시 원문과 시행일·부칙을 함께 확인합니다. **고시 발행부터 DB 반영까지의 보장된 시간은 확인되지 않았습니다.**

### E. 법령·고시 원문: 최종 법적 기준

- 법제처 API: https://open.law.go.kr/LSO/openApi/guideList.do
- 화학물질안전원: https://nics.mcee.go.kr/
- 화학물질종합정보시스템: https://icis.mcee.go.kr/

법제처는 현행·연혁 법령, 행정규칙, 변경이력 API를 제공합니다. 화학물질안전원은 현재 기후에너지환경부 체계이며 관련 화학물질 정보·민원 시스템을 안내합니다. [출처 9, 10]

**누가 언제 올리나?** 법령·고시는 소관기관이 제·개정하고 공식 원문을 공개하며, 법제처가 법령정보로 제공합니다. 업데이트는 제·개정 발생에 따른 것으로, 매월 정해진 날 갱신되는 제품 목록과는 다릅니다.

**자동 수신:** 국가법령정보센터의 개정법령·입법예고 메일링 서비스를 보조 알림으로 쓰고, 프로그램은 API로 원문·연혁을 비교하는 것이 좋습니다. 입법예고는 확정된 법령과 분리해야 합니다. [출처 11]

## 3. 최대 저장량·합산 범위는 공공 API가 아니라 사업장 자료가 필요합니다

### 최대량은 하나의 숫자로 합치지 마세요

프로그램에 최소한 다음 네 값을 따로 둡니다.

1. **허가·신고상 수량**
2. **설계·운영상 최대 저장 가능량**
3. **현재 실제 재고량**
4. **과거 관측된 최고 재고량**

허가량을 현재 재고로 쓰거나, 과거 최고량을 앞으로의 운영 최대량으로 단정하면 안 됩니다.

실제량은 ERP·WMS·탱크 계측으로 수집하고, 운영 최대량은 생산·물류·시설 담당자가 근거를 확인하며, 허가자료와 법적 적용은 EHS 담당자가 검토하는 역할 분담을 권합니다.

### 합산은 먼저 ‘어디까지 묶는지’를 정해야 합니다

[MCP 확인] 위험물안전관리법 제5조제5항은 **같은 장소**의 각 위험물 수량을 해당 지정수량으로 나눈 값의 합계가 1 이상이면 지정수량 이상으로 봅니다. [법령 근거 L3]

```text
지정수량 배수 합계 = Σ(각 위험물 수량 ÷ 해당 위험물 지정수량)
```

하지만 **‘같은 장소’를 회사 전체, 건물별, 창고별로 임의 결정해서는 안 됩니다.** 배치도·허가 경계·시설 구조 등을 검토하고 불명확하면 관할 소방서 확인을 받아야 합니다.

또한 이 산식을 다른 법령의 저장량·취급량 판정에 그대로 재사용하면 안 됩니다. **규제별 합산 범위와 계산식을 별도 관리**해야 합니다.

## 4. 업데이트를 자동으로 받는 권장 구조

아래 주기는 **기관의 공식 갱신 주기가 아니라 권장 운영 설계**입니다.

- **공급자 MSDS:** 개정 이메일·포털 문서 수신 즉시 비교.
- **KOSHA:** 매일 관심 물질의 `lastDate` 확인.
- **소방청·한국환경공단:** 매일 관심 물질 응답 비교.
- **법령·고시:** 매일 제·개정 확인, 별도로 시행일 도래 시 재판정.
- **재고:** 입고·출고·이동 이벤트마다 갱신.
- **시설·허가:** 변경 승인·신고 자료 확보 시 갱신.

**공개 문서에서 물질별 변경을 보내주는 공식 webhook·RSS는 확인하지 못했습니다.** 따라서 API는 기본적으로 ‘기관이 변경을 보내주는 방식’이 아니라 **우리 프로그램이 조회해 변경을 감지하는 방식**으로 설계하는 것이 현실적입니다.

자료마다 다음을 보관하면 추적이 가능합니다.

```text
출처·원본 파일 / 제품·물질 ID / 자료 개정일 / 수집일
내용 해시 / 고시번호·법령 버전 / 시행일·적용례
적용 제품·로트·시설 / 검토자·승인 상태
```

특히 **포털 수정일, 개별 자료 개정일, 법적 시행일, 우리 시스템 수집일은 서로 다른 날짜**입니다.

## 결론: 이렇게 기준을 잡으면 됩니다

> **실제 제품 성질은 공급자 자료·필요한 시험으로 확인하고, 규제 기준은 공식 고시·법령으로 확인하며, 수량과 합산 대상은 사업장 자료로 확인한다. API는 검색·교차검증·변경 감지를 담당한다.**

프로그램에서는 **자료 없음, 함량 범위가 기준선을 걸침, 시험조건 불명확, 합산 경계 미확정**을 ‘규제 없음’으로 처리하지 말고 **판정보류·추가 증빙 요청**으로 보내는 것이 핵심입니다.
