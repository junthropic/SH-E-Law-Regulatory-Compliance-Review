## 2. 결정

- 주색 남색 `#1d4f91` 하나. 나머지 색은 상태만 뜻한다.
- 글꼴 Pretendard 1.3.9(SIL OFL 1.1)를 번들(400·600·700, 전체 글리프 woff2 3개 2,342,904바이트). 대체 글꼴 "Malgun Gothic", system-ui. 외부 글꼴 주소는 쓰지 않는다.
- 베타 표시: 머리글 브랜드 옆 문장(기존 상수 "베타 — 검토 후보, 법적 판단 아님" 그대로) + 결과 화면 위 고지 띠 1개("검토 후보 — 법적 판단 아님, 베타") + 판정 카드마다 작은 "검토 후보 · 베타" 표시 1번. 1200px 이상에서는 고정 목차 아래에도 라벨을 둬서 결과를 아래로 읽는 동안에도 보이게 했다.
- 기존 화면은 이번 범위에서 제외. 피드백 화면은 삭제. 다크 테마는 나중에(토큰만 정해 둠, 이번에는 넣지 않음).
- "위반 가능성"(`clear_risk`)은 지금 승인 0건이라 나오지 않지만, 나올 때를 대비해 별도 표시(진한 바탕 흰 글자 + ▲)를 만들어 뒀다. 빨강은 오류·삭제에만 쓴다.
- 데이터 화면의 "AI 전송에 동의" 버튼은 주 버튼에서 보조 버튼으로 낮췄다(동의를 유도하지 않도록). 영구 삭제는 빨간 테두리의 별도 칸으로 분리했다.

## 4. 화면별 변경

- 머리글: 흰 바탕 + 아래 1px 선, 선택 메뉴는 주색 밑줄. "본문 바로가기" 링크, 화면 전환 때 새 화면 제목(h1)으로 포커스 이동, 모든 요소에 2px 포커스 링(흰 간격 포함). 피드백 메뉴 삭제.
- 결과 화면(`ReviewPage.tsx`): 고지 띠 1개 → 검토 요청 → 요약 줄(판정 후보·상태별·근거 확인 필요 건수) + 주 버튼 "내보내기" 1개(다른 버튼은 모두 보조) → 판정 카드 → 사실 보완 → 자가 검토 → 내보내기. 1200px 이상 왼쪽 목차.
  - 판정 카드: 상태 표시 + "검토 후보 · 베타" 표시 1번, 제목, 근거 블록(근거 조문 칩·법률 기준일·승인), 결론, "추가로 확인할 것 N"(같은 문자열 한 번만, 기본 펼침, 8개 넘으면 768px 이상에서 2열), 다음 조치, 접힌 "기술 정보"(평가 기록 ID).
  - 표시용 분리(`beta/present.ts`): 결론 앞 "[검토 후보 — 법적 판단 아님, 베타] " 접두어와 조건 목록의 라벨 줄은 카드 표시가 대신 보여 주므로 화면에서만 뺀다. "법률 기준일 …", "근거 조문: …", "승인: …"은 근거 블록으로, "평가 기록 …"은 기술 정보로 옮긴다. 나머지 조건은 그대로 목록에 둔다. 서버 자료·내보내기는 바뀌지 않는다(V8-W03, e2e에서 내보낸 Markdown에 접두어·근거 줄이 그대로인지 확인).
  - "근거 확인이 필요한 부분": "법령명: 내용" 형식은 법령별로 묶고 개수 표시, 그 밖은 "공통". 기본 접힘(V8-W04).
  - 400px: 사실 표·서비스 표는 "이름: 값" 세로 쌓기, 페이지 가로 넘침 없음.
- 새 검토: 글자 수 안내(10자 이상·지금 N자), 비활성 이유, "처리 중…", 자료 목록·검토 기록의 불러오는 중·오류·빈 상태, 파일 올리기 오류를 그 칸 아래에.
- API 키: 상태를 글자+기호 표시로(미연결은 점선), 저장 오류를 입력칸 아래에(`aria-invalid`), 비활성 이유, "처리 중…"·"확인 중…", 자동 수집 스위치에 "저장됨", 외부 링크에 "(새 창)" 화면 낭독용 문구, 빈 열 머리글에 "작업".
- 데이터·백업: 각 칸의 불러오는 중·오류 상태, 보존 기간·미리보기·AI 동의를 바꾸면 "저장됨 — …", 백업·삭제 "처리 중…", 영구 삭제 칸 분리와 비활성 이유.

### 글꼴과 패키지

- `beta/beta.css`의 `@font-face`가 `./fonts/*.woff2`를 가리키고, 기존 베타 빌드(`node scripts/build-beta-v8.mjs`)가 그대로 `dist-beta/assets/Pretendard-*.woff2`로 내보낸다. `index.html`이 참조하는 파일은 여전히 JS·CSS 2개다(V8-W02).
- 서버 CSP(`default-src 'self'`)로 같은 출처 글꼴이 그대로 열린다. 측정에서 400·600·700 모두 `loaded`.
- MSIX 빌드는 `dist-beta/`를 통째로(`build-info.json` 제외) 복사하므로 글꼴도 바꾸지 않고 들어간다. 다만 패키지의 `THIRD_PARTY_NOTICES.txt`는 npm 패키지·pdfjs·Node 라이선스만 모아 만들어서 Pretendard가 빠졌다 → `scripts/build-msix-v8.mjs`에 Pretendard 항목 1줄을 더했다(`beta/fonts/LICENSE-Pretendard.txt` 전문). OFL 문서에는 메일 주소가 없어 패키지 검사 예외가 늘지 않는다. MSIX 자체는 이번에 다시 만들지 않았다(문법 검사만).
- 설치 파일은 글꼴만큼(약 2.3MB, 압축 전) 커진다.
