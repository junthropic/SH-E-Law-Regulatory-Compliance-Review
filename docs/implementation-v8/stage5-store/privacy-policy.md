# 개인정보 처리방침 — 한국 환경안전보건관리자 법령조회 프로그램 (베타)

시행일: TODO_EFFECTIVE_DATE · 대상 버전: 0.8.0.0 (베타) · 게시자: Junthropic

이 프로그램은 사용자 PC 안에서만 동작하는 Windows 앱입니다. 이 문서는 앱이 어떤 정보를 어디에 두고, 어떤 경우에 PC 밖으로 보내는지를 사실대로 적은 것입니다.

## 1. 제작자에게 보내는 정보: 없음

- 앱은 제작자(게시자)의 서버로 사용자 자료, 사용 기록, 오류 기록을 보내지 않습니다. 사용 통계·광고·분석 기능이 없습니다.
- 제작자는 사용자가 앱에 넣은 자료를 받거나 볼 수 없습니다.
- 앱 업데이트는 Microsoft Store가 합니다. 앱 안에 따로 업데이트를 내려받는 기능은 없습니다.

## 2. 앱이 PC 안에 저장하는 정보

| 저장하는 것 | 예 |
|---|---|
| 사용자가 입력하거나 올린 자료 | 검토 질문, 사업장 사실(인원·업종 등), 올린 문서 원본, 검토 결과, 사실 보완·자가 검토 기록 |
| 설정 | 보존 기간, AI 분석 동의 여부, 미리보기 스위치 등 |
| 사용자가 넣은 API 인증키 | 법제처 OC, 공공데이터포털 인증키, 도로명주소 승인키 |
| 기록 | 삭제 기록(시각·종류·식별번호·사유만, 파일 이름·본문 없음), AI 전송 기록(시각·주소·크기·해시·결과만, 본문 없음) |
| 공개 법령 자료 | 법령 원문·출처 정보(회사 자료가 아님) |

- 저장 위치: Windows가 이 앱에 배정한 사용자별 앱 데이터 폴더.
- 암호화: 검토·문서·설정 본문과 올린 원본 파일은 AES-256-GCM으로 암호화해 저장합니다. 그 암호화 키는 Windows 사용자 보호 기능(DPAPI)으로 감쌉니다. API 인증키도 DPAPI로 감싸 저장하고, 화면·응답·기록에 키 값을 표시하지 않습니다.
- 평문으로 두는 것: 공개 법령 원문과 그 검색 색인, 출처·규칙 정보, 일반 감사 기록(식별번호와 고정 문구). 회사 자료가 아니어서 검색할 수 있게 둡니다.

## 3. PC 밖으로 나가는 경우

앱은 아래 허용 목록의 주소로만, https로만 연결합니다. 그 밖의 주소로 가는 연결은 앱이 연결 전에 막습니다.

| 언제 | 어디로 | 무엇이 나가는가 |
|---|---|---|
| 사용자가 법령·공공 자료를 수집할 때 | 국가법령정보센터(`law.go.kr`), 공공데이터포털(`apis.data.go.kr`, `www.data.go.kr`), 도로명주소(`business.juso.go.kr`) | 조회에 필요한 검색어와 사용자가 넣은 그 기관의 인증키 |
| 공식 서식을 받을 때 | 고용노동부(`www.moel.go.kr`), 경기도(`www.gg.go.kr`), 화성시(`www.hscity.go.kr`) | 서식 파일 요청 |
| 사용자가 AI 분석을 켰을 때만 | OpenAI(`api.openai.com`, `auth.openai.com`) | 사용자가 미리보기로 확인하고 승인한 내용 |

- 각 기관·서비스로 보낸 정보는 그 기관·서비스의 정책에 따라 처리됩니다.
- **AI 분석은 기본으로 꺼져 있습니다.** 켜면 동의 기록을 남기고, 회사 자료가 담긴 요청은 보낼 내용을 그대로 보여 준 뒤 사용자가 승인한 1회만 보냅니다. 승인은 10분 동안만 유효하고, 동의를 철회하면 이전 승인은 무효가 됩니다. AI 분석을 켜면 입력 내용이 선택한 AI 서비스로 전송되며, 학습·보관 여부는 해당 서비스 정책을 따릅니다.
- AI 분석을 켠 상태에서는 자료가 담기지 않은 요청(예: 사용 가능한 모델 목록 조회, OpenAI 로그인)은 미리보기 없이 연결됩니다.
- 화면은 사용자의 기본 웹 브라우저에서 이 PC 안의 주소(127.0.0.1)로 열립니다. 브라우저 자체의 동작은 그 브라우저의 정책을 따릅니다.
- 앱 설치·업데이트 과정에서 Microsoft Store가 처리하는 정보는 Microsoft의 정책을 따릅니다.

설치판에서는 아래 기능을 꺼 두었습니다: 법령 MCP 조회, 제작자 저장소에서 법령 자료 받기, 국민신문고 자동 수집. 설정으로 켤 수 없습니다.

## 4. 보관과 삭제

- 기본: 사용자가 지울 때까지 PC 안에 암호화 상태로 보관합니다.
- 자동 삭제(선택): 설정에서 올린 원본을 30일·90일·365일 뒤 자동으로 지우게 할 수 있습니다. 앱을 시작할 때와 하루 1회 확인합니다.
- 직접 삭제: 검토를 하나씩 지우거나, "전체 삭제"를 입력해 올린 문서를 모두 지울 수 있습니다. 지운 자료는 목록·원본 받기·백업 목록에서 더 이상 읽을 수 없습니다. 원본을 지운 검토에는 "원본 삭제됨 — 재검토 불가"가 표시됩니다.
- **앱을 제거하면 저장된 자료가 삭제됩니다. 먼저 백업하세요.**
- 백업: 앱의 "데이터·백업" 화면에서 암호화된 백업 파일을 내보낼 수 있습니다. 같은 Windows 사용자로 앱을 제거하고 다시 설치한 뒤 복원되는 것을 확인했습니다. 다른 사용자나 다른 PC에서의 복원은 확인하지 않았고 되지 않을 수 있습니다. 백업에는 API 인증키와 설정이 들어가지 않습니다.
