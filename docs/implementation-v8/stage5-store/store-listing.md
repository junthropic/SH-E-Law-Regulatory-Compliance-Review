# Store 등록 문구 (한국어, 붙여넣기용)

Partner Center의 "Store 등록 정보 → 한국어(ko-KR)"에 그대로 붙여 넣는 문안이다. 모든 문장은 단계 1~4의 시험과 설치 시험으로 확인한 내용만 쓴다. 확인하지 않은 보안 인증·인프라 표현, AI 서비스의 학습 여부를 우리가 약속하는 표현, 정확도·적법성을 약속하는 표현은 쓰지 않는다(금지 표현 검사: `tests/v8-store-docs.test.ts` V8-D03).

## 1. 앱 이름

이미 정한 이름(매니페스트 `DisplayName`, Partner Center 예약 이름과 같아야 함):

- **한국 환경안전보건관리자 법률조회 프로그램**

지시서에 따른 후보 3개(이미 정한 이름이 1번):

| 후보 | 이름 | 비고 |
|---|---|---|
| 1 | 한국 환경안전보건관리자 법률조회 프로그램 | 현재 매니페스트 값 |
| 2 | 환경안전보건 법령 검토 도우미 (베타) | 짧음, 베타 표시 |
| 3 | EHS 법령 검토 후보 찾기 | 영문 약어 포함 |

이름을 바꾸면 Partner Center에서 새 이름을 예약하고, `packaging/msix/identity.json`의 `displayName`을 같은 값으로 바꾼 뒤 MSIX를 다시 만든다.

## 2. 짧은 설명 (Short description)

> 검토 후보 — 법적 판단 아님, 베타. 환경안전보건 담당자가 사업장 사실과 법령 원문을 대조해 확인할 의무 후보를 찾도록 돕는 PC용 프로그램입니다. 자료는 이 PC 안에 암호화해 저장하고 제작자에게 보내지 않습니다.

## 3. 상세 설명 (Description)

> 검토 후보 — 법적 판단 아님, 베타
>
> 환경안전보건 담당자가 자기 사업장 사실(인원, 업종, 취급 물질 등)과 법령 원문을 대조해 "확인해야 할 의무 후보"를 찾도록 돕는 Windows용 프로그램입니다. 결과는 법적 판단이 아니라 검토 후보이며, 근거가 부족한 항목은 "보류"로 남깁니다. 최종 판단은 담당자와 전문가가 해야 합니다.
>
> 이 앱이 하는 일
> • 질문과 사업장 사실을 입력하면 관련 법령 원문을 모아 검토 후보와 확인할 항목을 보여 줍니다.
> • 각 후보에 근거 조문과 법률 기준일을 붙이고, 근거가 모자라면 무엇을 더 확인해야 하는지 적습니다.
> • 산업안전보건법 안전관리자 판정 후보 미리보기(기본 꺼짐)를 켜고 끌 수 있습니다.
> • 사실 보완과 자가 검토(독립 검토 아님)를 기록하고, 결과를 Markdown·CSV로 내보냅니다.
> • 법제처·공공데이터포털·도로명주소 인증키를 사용자가 직접 넣어 최신 법령·공공 자료를 수집합니다. 키가 없는 출처는 "미연결 — 수집 안 됨"으로 표시됩니다.
>
> 자료 처리
> • 앱은 이 PC 안에서만 동작합니다. 화면은 기본 브라우저에서 이 PC 안의 주소(127.0.0.1)로 열립니다.
> • 검토·문서·설정과 올린 원본은 암호화해 저장하고, 암호화 키는 Windows 사용자 보호 기능(DPAPI)으로 감쌉니다.
> • 제작자 서버로 자료나 사용 기록을 보내지 않습니다. 외부 연결은 법령·공공 기관 주소와, 사용자가 켠 경우의 AI 서비스(OpenAI)로만 합니다.
> • AI 분석은 기본으로 꺼져 있습니다. 켜면 보낼 내용을 먼저 보여 주고 승인한 경우에만 보냅니다. 학습·보관 여부는 해당 AI 서비스 정책을 따릅니다.
> • 앱을 제거하면 저장된 자료가 삭제됩니다. 먼저 "데이터·백업" 화면에서 암호화 백업을 내보내세요.
>
> 알려진 한계
> • 베타입니다. 전문가 검토와 실제 사업장 검증을 거치지 않았습니다.
> • 판정 후보 상당수가 "사실·근거 확인 필요"(보류)로 나옵니다.
> • Windows(x64) 전용입니다. 설치 시험은 Windows 11 PC와 GitHub의 Windows 실행 환경에서 했고, Windows 10에서는 아직 시험하지 않았습니다.
> • 처음 실행할 때 들어 있는 법령 자료를 준비하느라 몇 분 걸릴 수 있습니다.
> • 백업은 같은 Windows 사용자로 다시 설치한 뒤 복원되는 것만 확인했습니다. 다른 사용자나 다른 PC에서는 복원되지 않을 수 있고, 백업에 인증키와 설정은 들어가지 않습니다.
> • 회사 정책으로 Microsoft Store가 막힌 PC에는 설치할 수 없습니다.
> • 스캔한 이미지 문서(OCR)는 읽지 못합니다.

## 4. 주요 기능 (Product features, 항목당 200자 이내)

1. 검토 후보 — 법적 판단 아님, 베타: 근거가 부족하면 보류로 표시
2. 사업장 사실과 법령 원문 대조, 근거 조문·법률 기준일 표시
3. 산업안전보건법 안전관리자 판정 후보 미리보기(기본 꺼짐)
4. 사실 보완·자가 검토 기록, Markdown·CSV 내보내기
5. 사용자 인증키로 법령·공공 자료 직접 수집
6. 자료는 PC 안에 암호화 저장, 제작자에게 전송 없음
7. AI 분석은 기본 꺼짐, 보낼 내용 미리보기 후 승인 시에만 전송
8. 암호화 백업 내보내기·가져오기, 보존 기간·영구 삭제 설정
