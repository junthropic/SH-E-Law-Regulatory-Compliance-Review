# Microsoft Store 스크린샷 (v8 베타)

- 크기: 1920x1080 PNG 6장 (뷰포트 1920x1080, 배율 1, 전체 페이지 아님)
- 합성 자료로 촬영: 가상 사업장 "가상 제조(주)", 합성 첨부 파일 1개. 실제 회사 자료·API 키 없음(키 전부 미연결).
- 촬영일: 2026-10-15 (베타 화면 개편 뒤 6장 모두 다시 촬영. 개편 내용은 `../../beta-redesign.md`)
- 촬영 방법: 새 임시 자료 폴더(`SHE_DATA_DIR`)·`SHE_INSTALLED=1`·서버 외부 요청 차단(`.local/store-shots/no-net.mjs`) 상태로 서버를 띄우고, `.local/store-shots/capture-store-v2.mjs`(Playwright, Edge 헤드리스)로 `/beta/` 화면을 찍음 — 서버·브라우저 모두 외부 요청 0건, 화면 오류 0건. 촬영 뒤 서버 종료, 임시 자료 폴더 삭제.
- 촬영 스크립트가 장마다 화면 안에 라벨 전문("베타 — 검토 후보, 법적 판단 아님" 또는 "검토 후보 — 법적 판단 아님, 베타")이 있는지 확인했고, 6장 모두 눈으로도 확인했다. 경로·사용자 이름·메일 주소는 보이지 않는다. 피드백 화면은 없다(삭제됨).
