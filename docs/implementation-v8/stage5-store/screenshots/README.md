# Microsoft Store 스크린샷 (v8 베타)

- 크기: 1920x1080 PNG 6장 (뷰포트 1920x1080, 배율 1, 전체 페이지 아님)
- 합성 자료로 촬영: 가상 사업장 "가상 제조(주)", 합성 첨부 파일 1개. 실제 회사 자료·API 키 없음(키 전부 미연결).
- 촬영일: 2026-10-14
- 촬영 방법: 새 임시 자료 폴더(`SHE_DATA_DIR`)·`SHE_INSTALLED=1`·외부 요청 차단 상태로 서버를 띄우고, `.local/store-shots/capture-store.mjs`(Playwright, Edge 헤드리스)로 `/beta/` 화면을 찍음 — 서버·브라우저 모두 외부 요청 0건. 촬영 뒤 서버 종료, 임시 자료 폴더 삭제.

| 파일 | 화면 이름 | 보이는 내용 |
|---|---|---|
| `01-review-result.png` | 검토 결과 (판정 후보) | 베타 배지, "검토 후보 — 법적 판단 아님, 베타" 라벨, 안전관리자 미리보기 켜짐, 안전관리자 선임(인원) 후보의 법률 기준일·근거 조문, 추가 확인·다음 조치 |

| `03-api-keys.png` | API 키 설정 | 법제처 OC·공공데이터포털·도로명주소 키 모두 "미연결 — 수집 안 됨", 발급처 안내 |

- 모든 장에 베타 라벨이 보인다(01~04는 머리 배지 또는 라벨, 05는 미리보기 설명, 06은 후보 결론).
- 05·06은 `.local/store-shots/recapture-05-06.mjs`로 같은 조건(새 임시 자료 폴더)에서 다시 찍었다. 검토 결과 화면은 후보 카드의 라벨과 내보내기 버튼 사이가 약 1,900px이라 한 화면(1080px)에 함께 담을 수 없어서, 06은 라벨이 있는 후보 카드와 사실 보완을 담았다.
