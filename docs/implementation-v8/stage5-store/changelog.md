# 버전 번호와 변경 기록

## 버전 번호

- 패키지 버전은 `packaging/msix/identity.json`의 `version`이 정한다(형식 `주.부.수정.0`, Store 규칙상 마지막 자리는 0).
- Store에는 같은 버전을 다시 올릴 수 없다. 업로드한 뒤 고치면 세 번째 자리를 올린다(0.8.0.0 → 0.8.1.0). 기능이 크게 바뀌면 두 번째 자리를 올린다.
- `package.json`의 `version`(0.1.0)은 개발용 값이며 패키지 버전과 다르다.

## 0.8.3.0 (베타 — 미제출)

- 보안 검토 F-07: ChatGPT 연결 해제가 저장된 등록 정보(이메일·subject·clientId)도 지운다. 해제 뒤 다른 계정으로 연결할 수 있다. 원격 폐기·로컬 토큰 삭제·안내 문구는 그대로다(V8-G08·G09).
- 보안 검토 F-10: 모든 응답에 `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-origin`, 기기 기능을 막는 `Permissions-Policy`를 붙였다. ChatGPT 로그인(새 창·같은 탭 모두), 글꼴, 내려받기는 그대로 동작한다(V8-N04, 로컬 브라우저 확인).
- 보안 검토 F-11: 저장 암호화와 암호화 백업의 GCM 인증 태그를 16바이트로 고정했다. 잘린 태그는 거부하고, 기존 자료·백업은 그대로 열린다(V8-E06·E07).
- 보안 검토 F-12: GitHub Actions를 전체 커밋 SHA로 고정했다(태그는 주석, V8-M11).
- 보안 검토 F-13: MSIX에 넣는 node.exe를 그 버전의 공식 SHASUMS256과 대조한다. 목록은 `msix.yml`의 빌드 전 단계에서만 받고, 다르면 빌드가 실패한다. 결과는 `msix-build.json`에 기록된다(V8-M12, CI에서 아직 실행 안 함).
- 보안 검토 F-08(평문 저장 범위)·F-14·F-15는 문서로 남겼고, F-09는 사용자 결정(2026-10-17)으로 다음 버전에서 고친다(`../security-review-plan.md` 10절).
- 베타 화면 데이터 처리 안내의 "기존 화면의 백업" 항목: 설치판에서는 "설치판에서는 기존 화면의 JSON 백업을 지원하지 않습니다. 이 화면의 암호화 백업을 쓰세요."로 바꿨다(사용자 승인 2026-10-17, V8-K03). 개발 모드 문구는 그대로다.
- 개인정보 처리방침 "대상 버전"을 0.8.3.0으로 바꿨다(게시 페이지 수정 필요).
- 화면 파일은 바꾸지 않았다.

## 0.8.2.0 (베타 — 미제출)

- 보안 검토 F-06: 설치판에서 ChatGPT 로그인(코드 교환)·토큰 갱신·원격 세션 종료가 외부 통신 검사에 막히던 문제를 고쳤다. 검사가 양식(URLSearchParams) 본문을 실제로 보내는 글자 그대로 읽는다. AI 전송 동의가 꺼져 있으면 지금처럼 막힌다(V8-G01~G07).
- 보안 H1: 설치판(`SHE_INSTALLED=1`) 서버는 실행 토큰 없이 시작되면 아무것도 열지 않고 종료한다(V8-X08·X11·X12). 실행기는 매번 토큰을 넣으므로 정상 실행은 그대로다.
- 보안 검토 F-05: 외부 통신 검사가 `http(s).request`의 실제 접속 대상(options의 hostname/host)을 본다. fetch 리다이렉트는 한 단계씩 다시 검사한다(20번 한도, 다른 출처로는 인증 머리글을 넘기지 않음). 모든 TCP·TLS 연결도 허용 목록 밖 주소면 막는다(V8-O03~O06).
- 보안 검토 F-02: 이번 버전에서는 코드를 바꾸지 않고 남은 위험으로 문서화했다(`../security-review-plan.md` 9.7절). 사용자 결정(2026-10-17): 이번 버전은 남은 위험으로 문서화, 다음 버전에서 수정.
- 개인정보 처리방침 "대상 버전"을 0.8.2.0으로 바꿨다(게시 페이지 수정 필요).
- 화면 파일은 바꾸지 않았다.

## 0.8.1.0 (베타 — 미제출)

- 보안 검토 F-01: 인코딩된 `/api` 주소로 세션·CSRF·실행 토큰 검사를 피하던 문제를 고쳤다(라우터가 고른 경로로 판단, V8-X09).
- 보안 검토 F-04: 설치판에서 기존 화면의 평문 JSON 백업·복원을 막았다(암호화 백업은 그대로, V8-X10).

- 보안 H7: 자식 프로세스 환경 허용 목록과 PowerShell 절대 경로(2026-10-16, V8-H01~H10). 환경 변수로 지정한 프록시·추가 CA는 쓰지 않는다(`../security-review-plan.md` 8.3절).
- 개인정보 처리방침 "대상 버전"을 0.8.1.0으로 바꿨다(2026-10-16 사용자 결정, 게시 페이지 수정 필요).
