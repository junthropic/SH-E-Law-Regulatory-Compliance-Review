# 버전 번호와 변경 기록

## 버전 번호

- 패키지 버전은 `packaging/msix/identity.json`의 `version`이 정한다(형식 `주.부.수정.0`, Store 규칙상 마지막 자리는 0).
- Store에는 같은 버전을 다시 올릴 수 없다. 업로드한 뒤 고치면 세 번째 자리를 올린다(0.8.0.0 → 0.8.1.0). 기능이 크게 바뀌면 두 번째 자리를 올린다.
- `package.json`의 `version`(0.1.0)은 개발용 값이며 패키지 버전과 다르다. 피드백 파일의 `environment.appVersion`도 지금은 `"0.1.0"` 고정값이다(아래 "알려진 문제").

## 알려진 문제 (0.8.0.0)

- 피드백 파일의 `environment.appVersion`이 패키지 버전(0.8.0.0)이 아니라 `"0.1.0"`으로 나온다(`server/beta-v8.ts`).
- 시험 번호 `V8-S01`이 두 시험(`tests/v8-beta.test.ts`, `tests/v8-package-scan.test.ts`)에 겹쳐 쓰였다.
- 보안 검증 계획(`../security-review-plan.md`)은 준비만 했고 실행하지 않았다. H1(같은 PC의 다른 사용자·프로세스 접근)은 위험도 높음.
