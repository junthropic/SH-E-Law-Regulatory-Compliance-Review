## 1. 설치

1. 아래 Store 링크를 Windows PC에서 엽니다: TODO_STORE_LINK
2. Microsoft Store 앱에서 "받기(설치)"를 누릅니다. 관리자 권한은 필요 없습니다.
3. 시작 메뉴에서 "한국 환경안전보건관리자 법령조회 프로그램"을 실행합니다.
4. 기본 브라우저에 화면이 열립니다(주소 `http://127.0.0.1:…/beta/`, 이 PC 안의 주소). **처음 실행할 때는 들어 있는 법령 자료를 준비하느라 몇 분 걸릴 수 있습니다.** 두 번째부터는 몇 초 안에 열립니다.
5. 끝낼 때는 화면 오른쪽 아래 알림 영역의 앱 아이콘에서 종료합니다.

필요 환경: Windows(x64). 설치 시험은 Windows 11 PC와 GitHub의 Windows 실행 환경에서 했고, Windows 10에서는 아직 시험하지 않았습니다.

## 2. 처음 할 일

- **API 키 설정**: 최신 법령·공공 자료를 받으려면 "API 키 설정" 화면에서 법제처 OC(필수)와, 필요하면 공공데이터포털 인증키(31개 서비스 공통)·도로명주소 승인키를 넣습니다. 키는 무료로 발급받는 사용자 본인의 키입니다. 키가 없는 출처는 "미연결 — 수집 안 됨"으로 표시되고, 그 근거가 필요한 판정은 보류됩니다. 키 값은 화면·기록에 다시 표시되지 않습니다.
- **법령 자료 갱신**: 앱에 들어 있는 공개 법령 초기 자료는 앱을 만들 때의 자료입니다. 설치판은 이 자료를 인터넷으로 받아오지 않으므로, 최신 법령이 필요하면 API 키를 넣고 직접 수집하세요. 새 앱 버전이 나오면 Store가 업데이트하면서 새 초기 자료가 함께 들어갑니다.

## 3. 데이터 처리 안내

- 자료는 이 PC 안, 이 앱 전용 사용자 폴더에 암호화해 저장합니다(AES-256-GCM, 키는 Windows DPAPI로 보호).
- 제작자 서버로 자료나 사용 기록을 보내지 않습니다.
- 외부 연결은 법령·공공 기관 주소와, 사용자가 켠 경우의 AI 서비스(OpenAI)로만 합니다. 그 밖의 주소는 앱이 연결 전에 막습니다.
- AI 분석은 기본 꺼짐입니다. 켜면 보낼 내용을 먼저 보여 주고, 승인한 1회만 보냅니다. AI 분석을 켜면 입력 내용이 선택한 AI 서비스로 전송되며, 학습·보관 여부는 해당 서비스 정책을 따릅니다.
- 보존: 기본은 계속 보관. "데이터·백업" 화면에서 올린 원본의 자동 삭제(30·90·365일)와 영구 삭제를 고를 수 있습니다.
- **앱을 제거하면 저장된 자료가 삭제됩니다. 먼저 백업하세요.** 백업은 "데이터·백업" 화면의 "백업 내보내기"로 암호화 파일을 만듭니다. 같은 Windows 사용자로 다시 설치한 뒤 "가져오기"로 복원되는 것을 확인했습니다. 다른 사용자나 다른 PC에서는 복원되지 않을 수 있고, 백업에 API 키와 설정은 들어가지 않습니다(복원 후 다시 넣어야 합니다).

## 4. 알려진 한계

- 베타입니다. 전문가 검토와 실제 사업장 검증을 거치지 않았습니다. 판정 규칙은 모두 "후보"로만 쓰이며 위반 확정 결과는 내지 않습니다.
- 판정 후보 상당수가 "사실·근거 확인 필요"(보류)로 나옵니다. 올린 문서와 판정 후보를 아직 자동으로 연결하지 않습니다.
- 안전관리자 판정 후보 미리보기는 기본 꺼짐이며, 법률 기준일 2026-10-08 기준입니다.
- 자가 검토는 "자가 검토 — 독립 검토 아님"으로 표시됩니다.
- Windows 전용입니다. 회사 정책으로 Store가 막힌 PC에는 설치할 수 없습니다.
- 처음 실행할 때 몇 분 걸릴 수 있습니다.
- 앱을 제거하면 자료가 삭제됩니다. 백업 복원은 같은 Windows 사용자에서만 확인했습니다.
- 스캔한 이미지 문서(OCR)는 읽지 못합니다.
- 설치판에서는 법령 MCP 조회, 제작자 저장소에서 법령 자료 받기, 국민신문고 자동 수집을 지원하지 않습니다. 국민신문고 회신은 직접 내려받아 자료함에 올리세요.
