# 0010. 혼자 쓰는 설치를 위해 자가 검토를 허용하고 독립 검토로 세지 않는다

상태: 확정

## 맥락
검토자 확인과 별개로, 한 사람이 자기 PC에서 쓰는 앱에서는 독립된 검토자를 구하기 어렵다. 그래도 사용자가 결과를 스스로 확인했다는 기록은 필요하다.

## 결정
- 완료된 검토에 대해 메모 15자 이상과 사실·근거·한계 세 가지 확인으로 자가 검토를 남길 수 있다.
- 항상 "자가 검토 — 독립 검토 아님"으로 표시하고 내보내기에도 붙인다.
- 독립 검토 경로(작성자와 검토자가 다른 경로)는 바꾸지 않는다.

## 검토한 대안
- 자가 검토 금지: 혼자 쓰는 사용자는 검토 완료 표시를 할 수 없다.
- 자가 검토를 독립 검토로 인정: 결과의 신뢰도를 과장한다.

## 결과
- 자가 검토만 있는 결과를 외부에 "검토 완료"로 제시하면 오해가 생기므로 표시 문구를 지우는 경로를 만들지 않는다.
