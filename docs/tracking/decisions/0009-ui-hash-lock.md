# 0009. 두 화면을 해시로 잠그고 바꿀 때는 사용자 승인을 받는다

상태: 확정

## 맥락
화면 문구와 표시는 법적 오해 방지와 Store 심사 자료(스크린샷)에 직결된다. 반복된 서버 보강 작업 중 화면이 의도치 않게 바뀌는 일을 막아야 했다.

## 결정
- 옛 화면 29개 파일과 베타 화면(`beta/`, `dist-beta/`, 베타 빌드 설정, `beta-contract`)을 SHA256 해시로 잠근다. 시험이 하나라도 바뀌면 실패한다.
- 바꿀 때는 사용자 승인 → 수정 → `freeze-ui-v8.mjs`로 재잠금 순서다.
- 잠금을 풀었다가 다시 묶어도 기능은 그대로 작동해야 한다.

## 검토한 대안
- 코드 리뷰 규칙으로만 막기: 서버 작업 중 실수로 바뀌는 것을 자동으로 못 잡는다.
- 옛 화면만 잠금: 베타 화면이 Store 심사 대상인데 잠기지 않는다.

## 결과
- 사소한 문구 수정도 승인과 재잠금이 필요하다.
- 화면이 필요한 기능(수동 보완·독립 검토 화면)은 잠금을 풀어야 만들 수 있다.
