# 0007. 공개 법령 번들 갱신은 자동이 아니라 사람이 한다

상태: 확정

## 맥락
번들은 앱에 포함되어 모든 사용자가 같은 근거에서 시작한다. 자동 갱신은 틀린 개정, 일시적 응답 오류, 개인 흔적이 번들에 섞이는 사고를 사람이 보기 전에 배포할 수 있다.

## 결정
- 매주 자동 갱신은 2026-10-15에 껐다. 새 앱 버전을 만들기 전에 사람이 `sync`를 돌리고 `publish:check`를 통과시켜 커밋한다.
- 설치판은 앱 안에서 공개 번들을 직접 업데이트하는 기능도 끈다.

## 검토한 대안
- 매주 자동 갱신 + 자동 커밋: 검토 없이 배포 후보가 바뀐다.
- 앱 안 자동 업데이트: 설치판이 검토되지 않은 내용을 스스로 받아 들이게 되고 외부 통신 범위가 커진다.

## 결과
- 번들이 앱 버전 사이에 낡을 수 있다. 사용자는 자기 키로 직접 수집해 보완한다.
- 갱신은 개발자 법제처 키에 의존한다. 키를 지우는 계획과 충돌해 갱신 방법을 따로 정해야 한다.
