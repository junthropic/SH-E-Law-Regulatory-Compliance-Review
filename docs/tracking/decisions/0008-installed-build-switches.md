# 0008. 설치판은 위험한 기능을 끈다

상태: 확정

## 맥락
개발 실행에는 MCP 조회, 공개 법령 앱 내 업데이트, 전자민원 자동화, 평문 JSON 백업이 있다. 이들은 외부 호스트, 별도 브라우저 자동 조작, 키·자료가 평문으로 나가는 경로를 가진다. Store 설치판의 사용자는 회사 담당자이며 이 기능을 쓰는 경로로 상정하지 않았다.

## 결정
- `SHE_INSTALLED=1`이면 위 네 기능을 403과 안내 문구로 거절한다. 설치판은 실행 토큰이 없으면 시작하지 않는다.
- 개발 실행에서는 켜져 있다.

## 검토한 대안
- 설정으로 사용자가 켜게 한다: 비개발자가 자료 반출 경로를 직접 열 수 있다.
- 기능을 코드에서 지운다: 개발·시험에서 쓰는 기능과 시험이 사라진다.

## 결과
- 설치판과 개발 실행의 동작이 달라 시험은 두 모드를 모두 확인해야 한다.
- 이 기능을 설치판에서 쓰려면 새 결정이 필요하다.
