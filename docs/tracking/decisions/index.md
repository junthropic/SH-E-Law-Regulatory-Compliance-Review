# 결정 기록

되돌리기 어렵거나 다른 선택도 가능했던 결정만 적는다.

| 번호 | 결정 | 상태 |
|---|---|---|
| [0001](0001-local-only-store-install.md) | 로컬 전용 앱과 Microsoft Store 설치형 배포 | 확정 |
| [0002](0002-clear-risk-blocked.md) | 기본 경로에서 `clear_risk`를 내지 않는다 | 확정 |
| [0003](0003-candidate-layers-isolated.md) | 2~7단계 후보 계층을 기본 경로에 연결하지 않는다 | 확정 |
| [0004](0004-at-rest-encryption.md) | 저장 자료는 DPAPI로 감싼 키로 AES-GCM 암호화하고 공개 자료는 평문으로 둔다 | 확정 |
| [0005](0005-users-issue-own-keys.md) | 법제처·공공 API 키는 사용자가 직접 발급해 입력한다 | 확정 |
| [0006](0006-ai-per-send-consent.md) | AI 분석은 사용자가 켜고, 보낼 때마다 승인한다 | 확정 |
| [0007](0007-public-sync-manual.md) | 공개 법령 번들 갱신은 자동이 아니라 사람이 한다 | 확정 |
| [0008](0008-installed-build-switches.md) | 설치판은 위험한 기능을 끈다 | 확정 |
| [0009](0009-ui-hash-lock.md) | 두 화면을 해시로 잠그고 바꿀 때는 사용자 승인을 받는다 | 확정 |
| [0010](0010-self-review-allowed.md) | 혼자 쓰는 설치를 위해 자가 검토를 허용하고 독립 검토로 세지 않는다 | 확정 |
