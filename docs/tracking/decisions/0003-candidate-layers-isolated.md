# 0003. 2~7단계 후보 계층을 기본 경로에 연결하지 않는다

상태: 확정

## 맥락
2~7단계에서 컴플라이언스 평가, 기존 자료 연결, 안전관리자 의무, 교육 등을 만들었다. 이들은 기본 표가 암호화·소유권 구분이 없고, 보호 사례 결과가 평문 검토 표로 복사되며, 내보내기 점검이 옛 검토와 검토자용 묶음을 놓치는 상태에서는 개인 자료를 새게 할 수 있다. 화면 잠금 때문에 필요한 입력 화면도 만들 수 없다. 전문가 검토와 활성화도 끝나지 않았다.

## 결정
- 후보 계층은 `server/`에 두되 기본 앱 경로에 연결하지 않는다. 시험의 가짜 사용자(`synthetic: true`)로만 쓴다.
- 기본 경로의 유일한 접점은 `preview.safetyManagerV7` 스위치(기본 꺼짐)다.

## 검토한 대안
- 바로 연결: 위 조건이 풀리기 전에는 개인 자료 보호가 약하고 `clear_risk`가 나온다.
- 후보 코드를 지움: 시험·설계 근거가 사라지고, 나중에 다시 만드는 비용이 크다.

## 결과
- 후보 계층의 시험 통과가 기본 앱 동작을 보장하지 않는다.
- 연결하려면 조건을 하나씩 해소하고 사용자가 결정해야 한다.
