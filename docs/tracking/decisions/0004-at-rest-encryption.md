# 0004. 저장 자료는 DPAPI로 감싼 키로 AES-GCM 암호화하고 공개 자료는 평문으로 둔다

상태: 확정

## 맥락
사업장 질문·사실·문서는 PC에 파일로 남는다. 같은 PC의 다른 Windows 사용자나 백업 도구, 도난·반출된 디스크에서 읽히지 않아야 한다. 반면 공개 법령은 수백 MB에 가깝고 검색(FTS5)에 평문이 필요하다.

## 결정
- `reviews`, `documents`, `settings` 표의 본문과 업로드 원본 파일을 256비트 AES-GCM으로 암호화한다. 표 이름+ID를 인증 데이터로 묶는다.
- 데이터 키는 설치마다 하나 만들고 Windows 사용자 보호(DPAPI)로 감싼다. 다른 사용자·다른 PC에서는 열지 않는다.
- 공개 법령 자료와 일부 기록은 평문으로 둔다.

## 검토한 대안
- 사용자 비밀번호로 키 만들기: 비밀번호를 잃으면 자료가 영구히 사라지고, 비개발자 담당자에게 부담이다.
- 디스크 전체 암호화(BitLocker)에 맡기기: 앱이 켜 둘 수도 확인할 수도 없다.
- 모든 표 암호화: 공개 자료는 검색이 느려지고 이득이 없다.

## 결과
- 앱을 다른 PC로 옮기려면 암호화 백업 파일을 같은 Windows 사용자 계정에서 복원해야 한다. 다른 계정에서는 열 수 없다.
- 새 표를 만들 때 암호화 대상인지 정해야 한다.
