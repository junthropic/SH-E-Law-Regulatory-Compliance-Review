# 0005. 법제처·공공 API 키는 사용자가 직접 발급해 입력한다

상태: 확정

## 맥락
법령 데이터는 법제처 인증값과 공공데이터포털 등 서비스별 키가 있어야 받을 수 있다. 개발자의 키를 앱에 넣어 모든 사용자가 쓰면 호출량이 한곳에 몰려 막히거나 키가 노출된다.

## 결정
- 각 회사 담당자가 설치 뒤 직접 키를 발급해 설정 화면에 입력한다. 키는 Windows 사용자 보호 저장소에 둔다.
- 개발자 개인 키를 앱이나 저장소에 넣어 배포하지 않는다. 기본으로 들어 있는 것은 키 없이 만든 공개 법령 번들뿐이다.
- 다른 키가 이미 저장된 서비스는 교체 승인 없이는 덮어쓰지 않는다.

## 검토한 대안
- 개발자 키 내장: 키 노출·호출량 한도·제작자 책임 문제가 생긴다.
- 제작자 서버를 거치는 프록시: 제작자 서버를 두지 않는다는 결정과 충돌한다.

## 결과
- 처음 쓰는 사용자는 키를 발급받아야 하므로 도입 장벽이 있다. 번들이 이를 덜어 준다.
- 번들 갱신에는 개발자 쪽 키가 필요한데, 그 처리는 아직 정해지지 않았다.
