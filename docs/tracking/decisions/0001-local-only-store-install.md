# 0001. 로컬 전용 앱과 Microsoft Store 설치형 배포

상태: 확정

## 맥락
앱은 사업장 자료(위험물 종류·수량, 허가 여부, 업로드 문서)를 다룬다. 이 자료가 제작자나 제3자 서버에 모이면 각 회사 담당자는 자료 반출 승인을 받아야 하고, 제작자는 개인정보와 서버 보안을 책임져야 한다. 사용자는 회사 담당자 한 사람이 자기 PC에 설치해 쓰는 형태를 원했다.

## 결정
- 서버·저장소·화면을 모두 사용자 PC 안(`127.0.0.1`)에 둔다. 제작자 서버는 두지 않는다.
- 배포는 Microsoft Store의 MSIX 설치형이다. 각 회사 담당자가 자기 PC에 설치한다. Store 제출은 사용자가 직접 한다.
- GitHub 저장소는 비공개(Private)로 유지한다.
- 가격은 아직 정하지 않았다. 가격에 관한 표현을 문서와 안내문에 쓰지 않는다.

## 검토한 대안
- 클라우드 서비스(웹 앱): 로그인·권한·감사·서버 보안을 모두 직접 맡아야 하고, 회사마다 자료 반출 승인이 필요해 도입이 막힌다.
- 설치 파일(exe/zip)을 직접 배포: 업데이트, 서명, 신뢰 경고를 제작자가 감당해야 한다. Store는 서명과 업데이트 경로를 대신 제공한다.
- 저장소 공개: 개발 이력에 키·개인 흔적이 섞여 있을 수 있어 점검 전에는 위험하다. 공개로 얻는 이익이 지금은 없다.

## 결과
- 서버 쪽 계정·권한 체계가 없다. 보안 경계는 "같은 PC, 같은 Windows 사용자"다.
- 사용자 PC의 자료는 제작자가 복구해 줄 수 없다. 앱을 제거하면 자료가 지워지므로 백업 안내가 필수다.
- 법령 데이터를 서버에서 받아 줄 수 없다. 앱에 번들을 넣거나 사용자가 자기 키로 수집해야 한다.
- 저장소를 공개로 바꾸는 일은 개인 흔적 정리가 끝난 뒤 사용자가 다시 결정할 문제다.
