# 추가 공공 API 자료 조회

적용일: 2026-10-08

## 사용 순서

1. **공공자료 조회**에서 업무 분야별로 서비스(전체 32개)를 선택한다.
2. 서비스별 검색어와 날짜·인증번호·주소 등의 조건을 입력한다. 연결 체크에 사용한 예제값은 실제 검색에 자동으로 입력하지 않는다.
3. **조회 → 내용 확인**으로 기관의 응답 필드를 확인한다. 결정례는 상세 본문을, 국내 재해사례는 별도 키로 첨부파일 목록을 조회할 수 있다.
4. **자료함에 저장**한 뒤 새 법규 검토에서 해당 자료를 선택한다. 출처, 인증값을 제외한 호출 경로, 검색 조건, 조회 시각과 발췌 해시를 함께 보존한다.

## 입력과 제공 범위

| 자료 | 입력 | 제공 범위 |
|---|---|---|
| A01 결정례 | 검색어, 시작일·종료일 | 목록 및 문서번호를 대조한 상세 본문 |
| A02 GHS | 영문명·CAS·고유번호 | 분류·표지·유해성 세부 필드 |
| A03·A04 재해사례 | 제목·업종 / 게시판 번호 | 본문 필드 및 첨부파일 목록·링크. 파일 본문은 별도 확인 |
| A05 SIF | 재해유형, 업종 코드 | 고위험요인·대책 참고정보 |
| A06 화학사고 | 연도 | 연도별 목록. 물질·지역은 결과에서 확인 |
| A07·A08 폐기물 업체·처분 | 업체명, 식별 정보 / 처분일 | 사업장·허가범위·처분 자료 |
| A09·A10·B09~B13 행정 인허가 | 사업장·공사장명, 주소, 자치단체 코드 | 기관 제공 목록. 현재 허가증과 동일 사업장인지 별도 대조 |
| A11 토지이용 | 행위명 / 시군구·지역지구 코드 | 행위 코드 또는 행위제한. 연결된 조건·예외 QnodeCond도 보존 |
| A12 주소 | 도로명·지번주소 | 표준화 주소 후보 |
| B01~B06 인증·신고 | 인증서 번호 | 발급일·진위 응답. 설비 자체와의 동일성은 별도 확인 |
| B07·B08 소방용품 | 기간, 품목 분류·코드 | 형식승인·승인취소 |
| B14 폐기물 적합성 | 최초 인허가일 | 최초 허가일 기준 유효기간 참고정보 |

## 자연어 검토 연결

기존 법령·조례 및 6개 서비스에 GHS·고충민원 결정례·국내 재해사례를 추가했다. 사용자가 확인한 CAS만 물질 조회에 사용한다. 결정례 조회 범위는 기준일까지 최근 5개 연도이며 계획 화면에 기간을 표시한다. 식별정보가 필요한 다른 서비스는 사용자가 공공자료 조회에서 입력하고 저장한 자료를 검토에 첨부한다.

재해사례 API가 제목 조건을 반영하지 않고 전체 목록을 반환하는 실제 응답을 확인했다. 현재 페이지의 제목·업종을 대조하여 맞지 않는 항목을 제외하고, 기관 전체 건수와 조건 일치 건수를 혼동하지 않도록 범위를 표시한다. 전체 페이지를 자동 수집한 결과는 아니다.

자료 조회·저장은 법률 적용이나 위반 확정이 아니다. 검색 0건, 누락된 문서, 동일 이름의 업체·제품을 위반 근거로 자동 승인하지 않는다. 조례 위임·별표·부칙·예외·시행일 및 실제 현장 사실의 검증 절차는 계속 적용된다.

## 검증

- 추가 26개 서비스의 공식 예제 조건으로 실제 검색 응답 확인. 이 과정에서 사용자 인증값이나 기관 응답 원문을 Git에 저장하지 않음.
- 결정례 목록·상세 본문, 토지이용 행위제한·조건예외, 재해사례 응답의 검색조건 불일치도 별도 실제 확인.
- 격리 화면 시험: 26개 검색 양식, 상세·첨부목록, 출처를 포함한 26개 자료 저장, 모바일 레이아웃.
- 격리 자연어 시험: 사실 확인 → 조회 계획·동의 → 추가 자료 수집 → 기록 저장 → 검토 첨부. 부분 실패 시에도 명확한 위반으로 승격하지 않음.
- 실행 명령: `npm run check`, `npm run test:e2e:additional`, `npm run test:e2e:intake`, `npm run test:e2e:public`, `npm run test:e2e`.
