## Direction

A quiet document workspace for Korean EHS review. Keep the user's earlier request to remove AI-style promotional UI. Adapt the reference's navy, warm neutral surfaces, charcoal text, fine dividers and 8px component corners. No hero, purple marketing CTA, pastel feature-card grid, logo copying or external font requests.

## Tokens and hierarchy

- Navigation / primary action: #0a1530; hover #1a2a52.
- Workspace: #f6f5f4. Paper: #ffffff. Inset input: #fafaf9.
- Text: #37352f. Secondary text: #5d5b54. Dividers: #e5e3df.
- Korean system sans-serif, 34px page heading, 15–16px input text, 12–14px secondary information.
- 8/12/16/24/32px spacing. Desktop: 232px navigation, writing area, 250px contextual rail.
- Context rail shows existing connection and collection state only. Stored credentials and collected sources are not described as legally verified.
- Below 1200px put the rail after the form; below 800px use labelled top navigation; below 540px use single-column forms.

## Interaction and domain constraints

Preserve explicit model-transmission consent, three result categories, evidence gaps, source timestamps and existing action handlers. Keep visible keyboard focus, labelled inputs, native disclosures, keyboard-accessible file controls and reduced-motion support. No decorative animation, fabricated statistics or external assets.
