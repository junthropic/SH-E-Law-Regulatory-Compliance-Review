# 공개 법규 자료

초기 데이터는 비어 있습니다. 가공한 예시를 실제 법규로 제공하지 않습니다.

`npm run sync`는 별도 임시 DB에서 법제처 API만 수집하여 `bundle.json`을 갱신합니다. 출처별 수집 실패 시 이전 전문을 보존하고 실패 상태를 함께 기록합니다. `npm run publish:check`는 공개 데이터의 스키마·공식 출처·본문 해시를 검사합니다.

업무 질문, 첨부자료, 민원, OAuth·OC 값은 이 경로에 넣지 마세요. 원문은 공개 자료라도 출처와 기준일을 함께 표시합니다. API의 법규명 검색 결과만으로 전국의 적용 규정이 빠짐없이 확인되었다고 보지 않습니다.
