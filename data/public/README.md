# 공개 법규 자료

2026-10-03의 첫 GitHub 격리 수집 결과는 위험물 관련 18개 출처·39개 법규의 현행/연혁 225개 버전입니다. 가공한 예시를 실제 법규로 제공하지 않습니다. 자동 수집 자료는 사람이 원문·예외·별표를 대조한 상태와 구분하며 검증 승인 여부는 false로 유지합니다. 최신 수집 결과는 번들 안의 출처별 상태와 시각을 확인하세요.

`npm run sync`는 별도 임시 DB에서 법제처 API만 수집하여 `bundle.json.gz`를 갱신합니다. 현행·연혁 전문과 메타데이터를 생략하지 않고 gzip으로 압축합니다. 기존 `bundle.json`은 첫 성공적인 저장 시 교체됩니다. 출처별 수집 실패 시 이전 전문을 보존하고 실패 상태를 함께 기록합니다. `npm run publish:check`는 압축을 해제한 데이터의 스키마·공식 출처·본문 해시를 검사합니다. 전송 크기는 50MB, 압축 해제 크기는 256MiB로 제한합니다.

업무 질문, 첨부자료, 민원, OAuth·OC 값은 이 경로에 넣지 마세요. 원문은 공개 자료라도 출처와 기준일을 함께 표시합니다. API의 법규명 검색 결과만으로 전국의 적용 규정이 빠짐없이 확인되었다고 보지 않습니다.
