# data/public/ — 앱에 포함되는 공개 법령 번들

## 맡은 일
`bundle.json.gz`(위험물 관련 법규 근거의 현행·연혁 버전 모음. 건수는 갱신 때마다 바뀐다)와 설명 `README.md`. 서버가 시작할 때 이 번들을 근거 표로 가져온다.

## 맡지 않는 일
- 사용자가 만든 어떤 자료도 두지 않는다: 업무 질문, 첨부, 민원, 검토 기록, 인증값, OAuth 토큰.
- 검증 승인된 규칙이나 판단 결과를 담지 않는다.

## 반드시 지키는 것
- 번들은 격리 DB를 쓰는 공개 수집기(`npm run sync`)가 만든 공식 자료만 담는다. 손으로 고치지 않는다.
- 커밋 전에 `npm run publish:check`를 통과해야 한다(스키마, 공식 출처, 본문 해시). 실패하면 검사를 완화하지 말고 원인을 고친다.
- 번들에서 가져온 근거는 `verified=false`와 검증 메모 "공개 데이터 수입: 현장 검증 별도"로 시작한다. 이 상태를 번들 쪽에서 "검증됨"으로 바꾸지 않는다.
- 크기 한도: 전송 50MB, 압축 해제 256MiB.
- 갱신은 자동이 아니다. 새 앱 버전을 만들기 전에 사람이 수집하고 점검한다. 갱신에는 법제처 인증값이 필요하다.
- 설치판은 번들 파일이 지난 가져오기와 다를 때만 다시 가져온다.

## 시험
- `public-bundle` 시험이 가져오기와 검증 표시 유지를 지킨다. 번들을 바꾼 뒤에는 `publish:check`와 해당 시험을 모두 통과시킨다.
